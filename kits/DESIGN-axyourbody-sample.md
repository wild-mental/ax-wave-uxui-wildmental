# DESIGN.md — AX YOUR BODY (교재용 샘플)

> 이 문서는 교재의 예시로 새로 작성한 샘플 DESIGN.md입니다. 실습에서는 디자인 쇼핑으로 고른 DESIGN.md와 비교하거나, 그대로 하나의 후보로 써도 됩니다. 이 문서만 읽고도 같은 디자인을 재현할 수 있도록 썼습니다.

## 1. 디자인 방향

- **성격:** 차분한 코치. 사용자를 재촉하거나 탓하지 않고, 오늘 할 일 하나를 분명히 보여 준다.
- **원칙 1 — 한 화면 한 결정:** 각 화면은 사용자가 내릴 결정 하나를 중심에 둔다. 예) 대시보드는 "오늘 무엇을 할까".
- **원칙 2 — 근거가 보이는 AI:** AI의 판단·처방 옆에는 항상 근거와 한계를 함께 둔다.
- **원칙 3 — 빈틈을 허용하는 기록:** 기록이 빠진 날도 자연스럽게 보이고, 다시 시작하는 행동 하나를 제안한다.
- **원칙 4 — 색 없이도 읽힌다:** 상태와 위계는 색뿐 아니라 글자 라벨·아이콘 모양·선 굵기로도 구분한다.

## 2. 기본 설정값

### 색 (역할 기준)

| 역할 | 값 | 쓰는 곳 |
|---|---|---|
| 배경 | `#F7F7F5` | 페이지 바탕 |
| 표면 | `#FFFFFF` | 카드·입력칸 |
| 글자 | `#1D1F21` | 본문·제목 |
| 보조 글자 | `#5C6166` | 설명·단위 |
| 강조 | `#2F6B4F` | 주요 버튼·선택된 메뉴·진행 막대 |
| 경고 | `#B5542B` | 이상치·주의 |
| 선 | `#E2E3DF` | 구분선·카드 테두리 |

어두운 테마에서는 배경 `#141615`, 표면 `#1E2120`, 글자 `#ECEDEA`, 보조 글자 `#A3A8A4`, 선 `#2E322F`를 쓰고 강조·경고 색은 명도만 한 단계 올린다.

### 글꼴과 크기

| 용도 | 크기 / 굵기 / 줄 간격 |
|---|---|
| 화면 제목 | 24px / 700 / 1.3 |
| 카드 제목 | 17px / 600 / 1.4 |
| 본문 | 15px / 400 / 1.6 |
| 핵심 숫자 | 32px / 700 / 1.1 (숫자는 고정폭 숫자 사용) |
| 보조·단위 | 13px / 400 / 1.4 |

글꼴은 `Pretendard, "Noto Sans KR", system-ui, sans-serif` 순서로 지정한다.

### 간격과 그리드

- 기본 간격 단위는 8px. 카드 안 여백 20px, 카드 사이 16px, 절 사이 32px.
- 데스크톱은 최대 너비 1120px, 12열 그리드. 대시보드 카드는 4열/6열/12열 너비 중에서 고른다.
- 모바일(너비 600px 이하)은 한 열로 쌓고, 좌우 여백 16px.
- 모서리 둥글기: 카드 12px, 버튼·입력칸 8px, 칩 999px.

## 3. 화면 구조

```
[상단 바]  서비스 이름 · 주 메뉴(최대 5개) · 설정
[본문]     화면 제목 + 위치 표시(현재 메뉴 강조 + 굵은 밑줄)
           핵심 결정 영역 (가장 위, 가장 크게)
           근거 영역 (최근 기록·추이)
           보조 영역 (리서치 노트·추천 읽을거리)
[하단]     AI 코치 입력창 (모든 화면에 고정)
```

## 4. 콘텐츠 유형별 표현

### 핵심 지표 카드

```html
<section class="metric-card">
  <p class="metric-label">이번 주 훈련 강도</p>
  <p class="metric-value">중간 <span class="metric-unit">(RPE 평균 7.2)</span></p>
  <p class="metric-change"><span aria-hidden="true">▼</span> 지난주보다 낮음 · 디로드 주간</p>
</section>
```

```css
.metric-card { background:#FFFFFF; border:1px solid #E2E3DF; border-radius:12px; padding:20px; }
.metric-label { font-size:13px; color:#5C6166; margin:0 0 4px; }
.metric-value { font-size:32px; font-weight:700; line-height:1.1; margin:0; font-variant-numeric:tabular-nums; }
.metric-unit { font-size:15px; font-weight:400; color:#5C6166; }
.metric-change { font-size:13px; margin:8px 0 0; }
```

변화 방향은 색만으로 표시하지 않고 ▲▼ 기호와 문장("지난주보다 낮음")을 함께 쓴다.

### AI 판단 카드 (근거·한계 포함)

```html
<article class="ai-card">
  <p class="ai-tag">AI 코치 판단</p>
  <h3>오늘은 하체 훈련 강도를 70%로 낮추세요</h3>
  <details>
    <summary>근거 보기</summary>
    <ul><li>최근 3일 평균 수면 4.6시간</li><li>컨디션 2/5가 이틀 연속</li></ul>
  </details>
  <p class="ai-limit">한계: 수면·컨디션 기록만으로 판단했습니다. 통증이 있다면 전문가와 상의하세요.</p>
</article>
```

```css
.ai-card { border:2px solid #2F6B4F; border-radius:12px; padding:20px; background:#FFFFFF; }
.ai-tag { display:inline-block; font-size:13px; font-weight:600; border:1px solid currentColor; border-radius:999px; padding:2px 10px; }
.ai-limit { font-size:13px; color:#5C6166; border-top:1px dashed #E2E3DF; padding-top:8px; }
```

AI 판단 카드는 일반 카드보다 **굵은 테두리(2px)**와 "AI 코치 판단" 라벨로 구분한다.

### 기록 입력

- 빠른 입력이 기본: 한 줄 입력칸 + 최근 기록 칩 3개("어제와 같게", "지난 세션 반복").
- 정밀 입력은 "자세히" 버튼으로 펼친다. 처음부터 모든 칸을 보여 주지 않는다.
- 저장 실패 시 입력 내용을 지우지 않고, 입력칸 아래에 "저장하지 못했어요 · 다시 시도" 문장을 띄운다.

### 추이 차트

- 선 그래프 하나에 지표 하나. 여러 지표를 겹치지 않는다.
- 기록이 빠진 날은 선을 끊고, 끊긴 구간 아래에 "기록 없음" 라벨을 단다.
- 측정 조건이 다른 값은 속이 빈 점(○)으로 표시하고 범례에 "비표준 측정"이라고 적는다.

## 5. 상태 화면

| 상태 | 표현 |
|---|---|
| 빈 상태 | 회색 일러스트 대신 문장 한 줄 + 버튼 하나. "이번 주 기록이 아직 없어요. 오늘 컨디션부터 남겨 볼까요?" |
| 로딩 | 카드 자리에 같은 크기의 회색 상자 + "AI 코치가 기록을 읽는 중" |
| 오류 | 경고 색 테두리 + ⚠ 기호 + 원인 한 줄 + 다시 시도 버튼 |
| 이상치 | 해당 값 옆에 "확인 필요" 칩 + 측정 조건을 묻는 한 줄 |

## 6. 모달과 이미지

- 모달은 화면 너비의 최대 640px, 배경은 반투명 어둡게. 닫기 버튼은 오른쪽 위와 하단에 둘 다 둔다.
- 운동 동작 이미지는 4:3 비율로 자르고, 이미지 아래에 동작 이름을 글자로 쓴다.

## 7. 흑백 출력·접근성

- 모든 상태는 색 + 기호 + 문장 세 가지 중 최소 두 가지로 표현한다.
- 글자와 배경의 명도 대비는 본문 4.5:1 이상을 유지한다.
- 선택된 메뉴는 강조 색과 함께 굵은 밑줄(3px)로 표시한다.

## 1.2 사례 분석 메모 정리 지시문

교재 1.2절 · 워크시트: 익숙한 서비스의 사용 경험을 과업 관점으로 뜯어본 사례 분석 시트

써 보며 적은 메모를 `{메모 붙여 넣기}` 자리에 넣습니다.

```
나는 서비스기획을 공부하고 있어. 아래는 내가 건강 관리 앱 하나를 직접 써 보며 적은 메모야.
{메모 붙여 넣기}

1. 메모를 "사용자가 하려는 일 / 단계 / 막히는 지점 / 잘 돕는 지점" 표로 정리해 줘.
2. 막히는 지점마다 관련 있어 보이는 사용성 휴리스틱을 하나씩 짝지어 줘. 확신이 없으면 "추정"이라고 표시해 줘.
3. 특정 회사나 서비스를 깎아내리는 표현은 빼고, 관찰한 사실만 중립적으로 써 줘.
4. 내 메모에 없는 단계는 지어내지 말고, 빠진 것 같은 부분은 질문으로 남겨 줘.
```

## 1.5 과업 후보 넓히기 지시문

교재 1.5절 · 워크시트: 타깃 사용자의 해야 할 일과 불편을 정리한 과업·불편 목록

프로필 카드는 [공통 PRD와 프로필 카드](../textbook-materials/profile-cards.md)에서 내 프로필 것을 복사합니다. `[내가 찾은 단서]`의 예는 교재의 예이므로 내가 찾은 단서로 바꿉니다.

```
너는 서비스기획 보조야. 아래 가상 인물의 프로필 카드와, 내가 4주 기록에서 찾은 단서를 읽고
이 사람이 건강 관리 서비스 AX YOUR BODY로 해결하고 싶어 할 과업 후보를 12개 넓게 뽑아 줘.

[프로필 카드]
{프로필 카드 붙여 넣기 — 온라인 자료실에서 복사}

[내가 찾은 단서]
{예: 10/17(토)·10/18(일) 수면·식사 기록 없음 / 10/15 체중 86.8kg, 측정 조건 "전날 회식"}

규칙
- 모든 후보를 "~할 때, ~하고 싶다. 그래서 ~." 한 문장으로 써 줘.
- 기능 이름(알림, 챗봇, 추천 기능 등)을 쓰지 말고 상황과 하려는 일로 써 줘.
- 후보마다 근거를 "프로필 카드 / 기록 단서 / 추측" 중 하나로 표시하고, 추측인 후보는 맨 뒤에 모아 줘.
- 후보마다 그 상황이 얼마나 자주 올지 짐작해 적되, 짐작이라고 밝혀 줘.
```

## 1.6 페르소나 카드 초안 지시문

교재 1.6절 · 워크시트: 설계 판단의 기준이 되는 타깃 사용자 페르소나 카드

과업·불편 목록은 워크시트 문서의 본표를 복사합니다.

```
아래는 내가 정리한 과업·불편 목록과, 내가 고른 가상 인물의 프로필 카드야.
이걸 바탕으로 페르소나 카드 초안을 아래 칸 순서대로 써 줘.
칸: 한 줄 정체성 / 근거 사실 / 하루 장면 / 목표 우선순위 / 핵심 과업 / 이 사람이라면 이렇게 말할 것 / 설계 원칙 / 피해야 할 가정

[과업·불편 목록]
{과업·불편 목록 본표 붙여 넣기}

[프로필 카드]
{프로필 카드 붙여 넣기 — 온라인 자료실에서 복사}

규칙
- 근거 사실과 하루 장면은 내가 준 자료에 있는 날짜와 값만 써 줘. 없는 수치를 만들지 마.
- 핵심 과업은 과업·불편 목록의 우선순위 "상"에서만 가져와 줘.
- 과업과 관련 없는 취미·외모 같은 묘사는 넣지 마.
- 다 쓴 뒤, 성별·나이·직업만 보고 단정한 문장이 있는지 스스로 점검해서 목록으로 따로 알려 줘.
```

## 2.2 흐름이 바뀌는 날 찾기 지시문

교재 2.2절 · 워크시트: 고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드 · 여정 레인

첫 줄의 인물 소개는 교재의 예(박준혁)입니다. 내 프로필의 이름과 한 줄 소개로 바꾸고, 내 프로필 폴더의 CSV 내용을 붙여 넣습니다. 일반인 프로필(김도현·이서연)은 식사 기록이 빈 날도 중요한 단서이므로 `meal.csv`도 함께 넣습니다. CSV 파일은 붙여 넣는 대신 대화에 첨부해도 됩니다.

```
아래는 가상 인물 박준혁(38세, 웨이트 8년 차, 하이록스 병행)의 4주 운동·체성분·수면 기록이야.
날짜순으로 보면서 "흐름이 바뀌는 날"을 찾아 줘.
기준: 기록이 끊긴 날, 수치가 갑자기 바뀐 날, 운동 강도가 크게 달라진 날, 기록이 다시 시작된 날.
각 날짜마다 무엇이 바뀌었는지 한 줄로만 적고, 단계 이름은 붙이지 마. 단계는 내가 정할게.
{CSV 내용 붙여 넣기}
```

## 2.4 빠진 사건 찾기 지시문

교재 2.4절 · 워크시트: 고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드 · 사건 레인

사건 카드를 다 붙인 뒤에 씁니다. 사건 목록은 「[이벤트 보드 사용 가이드](../guides/event-board-guide.md)」 3부처럼 보드를 PDF로 내보내 Claude에게 글로 옮기게 한 뒤 붙여 넣습니다.

```
아래는 내가 만든 서비스 AX YOUR BODY의 이벤트 보드야. 사건은 모두 과거형이고 시간순이야.
{여정 단계별 사건 목록 붙여 넣기}
1) 단계와 단계 사이에서 빠진 것 같은 사건을 최대 5개 제안해 줘. 각각 왜 필요한지 한 줄로.
2) 과거형이 아니거나, 화면 이동·내부 동작처럼 사건이 아닌 카드가 있으면 골라 줘.
새로운 기능이나 화면은 제안하지 마.
```

## 2.5 대상 객체 카드 점검 지시문

교재 2.5절 · 워크시트: 서비스가 다루는 대상 객체·속성·관계를 정리한 대상 객체 카드

첫 줄의 인물 소개는 교재의 예(박준혁)입니다. 내 프로필로 바꿉니다.

```
아래는 AX YOUR BODY의 대상 객체 카드야. 사용자는 가상 인물 박준혁(웨이트 8년 차, 하이록스 병행)이야.
{대상 객체 카드 표 붙여 넣기}
1) 관계 칸에서 양쪽이 서로 맞지 않는 곳(한쪽은 1:N, 다른 쪽엔 관계 없음 등)을 찾아 줘.
2) 핵심 속성 중 계산으로 얻을 수 있는 값이 섞여 있으면 알려 줘.
3) 대상 객체가 아니라 다른 대상 객체의 속성이어야 할 것 같은 항목이 있으면 이유와 함께 알려 줘.
새 대상 객체는 추가하지 말고 지적만 해 줘.
```

```
내용을 고쳐 쓰지는 말고 질문만 해 줘.
{서비스 구조 설명서 붙여 넣기}
```

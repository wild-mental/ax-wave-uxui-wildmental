# 문서 템플릿 (워크시트)

「웹서비스 UX/UI 기획」(4-1) 교재의 문서 템플릿입니다. 4일 동안 문서 템플릿의 워크시트는 모두 `worksheet.md` 한 파일에 씁니다. 이 폴더의 파일을 직접 고치지 말고, 내 비공개 저장소로 옮겨 씁니다. 명령어는 쓰지 않고 GitHub 웹 화면에서만 작업합니다.

## 시작하기

1. 오른쪽 위 **+ → New repository**에서 저장소 이름을 `axyourbody-worksheet`로 쓰고, 공개 범위는 반드시 **Private**(비공개)를 고른 뒤 만듭니다.
2. 이 폴더의 [`worksheet.md`](worksheet.md)를 열고 **Copy raw file**(복사 아이콘)로 내용 전체를 복사합니다.
3. 내 저장소에서 **creating a new file**(또는 **Add file → Create new file**)을 누르고, 파일 이름 `worksheet.md`로 붙여 넣은 뒤 **Commit changes**를 누릅니다.
4. 내 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다.

클릭 순서는 교재 부록 A-2와 온라인 가이드 「GitHub 워크시트 저장소 가이드」를 봅니다.

## 내 저장소에 생기는 파일

| 파일 | 쓰임 |
|---|---|
| `worksheet.md` | 문서 템플릿의 워크시트 전부와 Claude에 넘길 서비스 구조 설명서. 맨 위의 「쓰는 법」부터 읽습니다 |
| 이미지 파일 | 워크시트에 연결할 사진과 화면 이미지(개념 ERD 손그림, 재현 시험 화면 등). 저장소 맨 위에 올립니다 |
| `my-own-DESIGN.md` | Day 4에 올리는 나만의 DESIGN.md |

## 꼭 지킬 것

- 내 워크시트 저장소는 끝까지 **Private**으로 두고, 강사 `wild-mental`만 초대합니다.
- 워크시트 저장소에서는 **GitHub Pages를 켜지 않습니다.**
- 배포는 따로 만드는 배포 전용 **공개(Public) 저장소**로만 하고, 거기에는 `index.html`과 `favicon.svg` 두 파일만 올립니다(교재 부록 A-6).

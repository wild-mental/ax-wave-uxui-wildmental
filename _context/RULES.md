# 온라인 자료 작성 규칙

인쇄본 교재(2026-11-05 출력본, 컬러판·흑백판 105쪽)와 같은 규칙입니다. 상위 프로젝트 `docs/4-1/TEXTBOOK_SPEC.md` §10·§11·§24·§25·§26·§31·§32에서 온라인 자료에 해당하는 것만 옮겼습니다.

> 이 저장소는 GitHub Pages로 **공개**됩니다. `_context/`는 사이트에는 안 보이지만 저장소에서는 누구나 볼 수 있습니다. 강사용 내용(평가·정답·운영 메모)은 여기에도 넣지 않습니다. 그런 내용은 상위 프로젝트 `docs/4-1/instructor-guide.md`(비공개)에만 둡니다.

## 1. 쓰는 말

1. 학생에게 하는 말만 씁니다. 독자는 "여러분", 문체는 합니다체. 안내형("~합니다", "~하세요").
2. 설계 의도("이 수업은 ~하려고"), 평가, 운영 시간표, 강사에게 하는 말은 쓰지 않습니다.
3. 전문용어는 처음 나올 때 `원어(우리말: 한 줄 풀이)`. 교재 부록 B 「용어 풀이」와 같은 풀이를 씁니다.
4. 예제를 인용할 때는 "OO 프로필로 실습한 예"라고 씁니다. 짝 활동 역할은 "테스트하는 나 / 써 보는 짝".

## 2. 정답을 싣지 않기 (T32)

- 데이터셋의 빠진 날·튀는 날 목록, 네 프로필의 과업 단서 표, 다른 프로필의 완성 예시를 싣지 않습니다.
- 데이터셋 CSV를 열어 결과를 뽑아 적지 않습니다. 날짜·값은 교재가 그 절에서 이미 보여 준 것만 인용합니다. 나머지는 `{날짜}` `{값}`처럼 비워 둡니다.
- "실수 → 고친 예"는 관통 예제 밖(도서관 앱, 배달앱, 택배 앱 등)에서 가져옵니다.

## 3. 개인정보

- 실제 사람의 신체 수치·검진 수치·증상·대화를 쓰지 않습니다. 캡처는 가상 프로필 데이터로만 찍습니다.
- 캡처에 개인 계정 이메일·실명·알림이 보이면 가리고 올립니다.

## 4. 이름은 인쇄본과 똑같이

가이드 제목(맨 위 `#` 줄)은 인쇄본의 `→ 온라인 가이드: 「이름」`과 글자 하나까지 같아야 합니다. 목록: `_context/ONLINE_MATERIALS_PLAN.md` §3-2 또는 `_context/guides.json`.

## 5. 코드 이름 금지 (T41)

W01~W14, K01~K12 같은 번호, v1·v2·v1-b 같은 버전 기호, 테마 기호 a·b·c, H1~H7, T1 같은 기호를 쓰지 않습니다. 위 4절의 이름만 씁니다. "용어집"이라는 말도 쓰지 않습니다(부록 B는 「용어 풀이」, 워크시트는 「용어 대조표」).

## 6. 한 곳 원칙

교재에 있는 칸 설명·작성 예시·지시문 전문은 가이드에서 되풀이하지 않고 "교재 2.5절의 [실습 안내] 표"처럼 가리킵니다. 가이드는 교재에 없는 것(화면 위치, 실수와 고친 예, 체크리스트 확인 방법, 막혔을 때)만 채웁니다. 각 가이드가 채울 것은 그 파일의 「작성 계획」에 있습니다.

## 7. 형식

- 표준 마크다운(GitHub 표·체크리스트 포함). HTML은 쓰지 않습니다(자리표시의 작성자용 주석 한 줄만 예외, 본문을 쓰면 지움).
- 이미지는 `guides/images/<가이드 파일 이름>-<번호>.png`에 두고 `![설명](images/…)`로 연결합니다. Mac·Windows 화면은 같은 단계에 나란히(표 두 칸 또는 연속 두 장).
- 화면 녹화(동영상·GIF)는 만들지 않습니다.
- 도구 조작 가이드(A-1~A-6)와 디자인 쇼핑처 가이드는 맨 아래에 "화면 확인 날짜: YYYY-MM-DD"를 적습니다.

# 교재 원문 발췌 — 「Claude 시작 가이드」

> 인쇄본 원고(`docs/4-1/manuscript/appendix-a-tools.md`)에서 이 가이드를 가리키는 부분을 그대로 옮겼습니다. 생성: `_context/gen_placeholders.py` (2026-11-04 원고 기준). 원고가 바뀌면 다시 뽑습니다.

## A-1 · Claude (웹·데스크톱 앱)

→ 온라인 가이드: 「Claude 시작 가이드」

1. 브라우저에서 claude.ai에 접속해 계정으로 로그인합니다. 데스크톱 앱을 쓰려면 같은 계정으로 앱에 로그인합니다.
2. 새 대화를 열고 본문 [실습 안내]의 지시문을 붙여 넣습니다. 지시문 안의 `{ }` 부분은 자기 내용으로 바꿉니다.
3. 결과를 받으면 바로 쓰지 말고, 근거가 있는지 확인한 뒤 디지털 문서 템플릿의 해당 워크시트 칸으로 옮깁니다.
4. 같은 주제의 대화가 길어지면 새 대화로 나누고, 앞 대화의 결론만 요약해 붙여 넣습니다.

주의할 점
- 실제 신체 수치로 실습한다면, 대화에 넣는 범위를 스스로 정하세요. 원하지 않으면 가상 프로필 데이터셋을 씁니다.
- 회사·타인의 개인정보는 넣지 않습니다.

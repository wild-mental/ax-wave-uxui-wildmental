# 교재 원문 발췌 — 「Figma 템플릿 만들기 가이드」

> 인쇄본 원고(`docs/4-1/manuscript/appendix-a-tools.md`)에서 이 가이드를 가리키는 부분을 그대로 옮겼습니다. 생성: `_context/gen_placeholders.py` (2026-11-04 원고 기준). 원고가 바뀌면 다시 뽑습니다.

## A-3 · Figma

→ 온라인 가이드: 「Figma 템플릿 만들기 가이드」

1. 브라우저에서 figma.com에 로그인합니다(무료 계정으로 충분합니다).
2. 새 디자인 파일을 만들고 이름을 `axyourbody_이름_프로필ID`로 바꿉니다. 예) `axyourbody_홍길동_f-athlete`
3. 온라인 자료실의 「Figma 템플릿」(자료실 저장소의 `figma-template` 폴더)에서 SVG 파일 네 개를 내려받습니다. 페이지를 네 개 만들어 「표지」, 「고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드」, 「과업별 화면 흐름 순서표와 화면 목록」, 「Google Stitch로 만든 테마별 화면 시안 비교표」로 이름을 붙이고, 페이지마다 해당 SVG를 캔버스에 끌어다 놓습니다. 칸 이름 상자와 완료 기준 체크리스트가 고칠 수 있는 도형과 글자로 들어옵니다.
4. 카드는 오른쪽 「복사해서 쓰는 카드」의 견본을 복사해서 늘리고, 칸 이름이 적힌 상자는 지우지 않습니다.
5. 제출할 때 공유 설정에서 **강사만 볼 수 있게** 초대하거나, 링크 공유 범위를 제한합니다. 공유 링크는 `worksheet.md` 맨 위의 Figma 링크 칸에 적습니다.

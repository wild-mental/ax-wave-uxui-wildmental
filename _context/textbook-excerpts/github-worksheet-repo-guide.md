## A-2 · GitHub 워크시트 저장소

→ 온라인 가이드: 「GitHub 워크시트 저장소 가이드」

문서 템플릿은 GitHub(깃허브: 파일을 저장소 단위로 보관하고 고친 이력을 남기는 웹 서비스)의 **비공개 저장소**에 내 사본을 만들어 씁니다. 명령어는 쓰지 않고 웹 화면에서만 작업합니다.

처음 한 번: 내 워크시트 저장소 만들기
1. github.com에서 무료 계정을 만들고 로그인합니다. 아이디는 Day 4의 배포 주소에 그대로 들어가므로, 실명을 드러내고 싶지 않다면 실명이 아닌 아이디로 만듭니다.
2. 오른쪽 위 **+ → New repository**를 누르고, 저장소 이름을 `axyourbody-worksheet`로 씁니다. 공개 범위는 반드시 **Private**(비공개)를 고른 뒤 **Create repository**를 누릅니다.
3. 자료실 저장소(주소는 이 부록 첫 쪽)에서 `worksheet-template` 폴더의 `worksheet.md`를 열고, 오른쪽 위의 **Copy raw file**(복사 아이콘)을 눌러 내용 전체를 복사합니다.
4. 내 저장소로 돌아와 **creating a new file** 링크(또는 **Add file → Create new file**)를 누르고, 파일 이름을 `worksheet.md`로 쓴 뒤 본문에 붙여 넣고 **Commit changes**를 누릅니다.
5. 저장소의 **Settings → Collaborators → Add people**에서 강사 GitHub 아이디 `wild-mental`을 초대합니다. 비공개 저장소에 강사만 초대한 상태가 "강사만 열람"입니다.

워크시트 쓰기
1. 저장소에서 `worksheet.md`를 열고 연필 아이콘(Edit)을 눌러 칸을 채웁니다.
2. 다 쓰면 **Commit changes**를 누르고, 뜨는 대화 상자에서 한 번 더 **Commit changes**를 눌러 저장합니다. 저장할 때마다 고친 이력이 남습니다.
3. **Preview** 탭으로 표가 제대로 보이는지 확인합니다. 체크리스트는 `- [ ]`의 칸 안에 `x`를 넣어 `- [x]`로 바꿉니다.
4. 표의 행이 더 필요하면 한 행을 복사해 아래에 붙입니다. 칸 안에는 `|` 기호를 쓰지 않고, 여러 항목은 쉼표(,)나 " · "로 나눕니다.
5. 사진이나 화면 이미지는 **Add file → Upload files**로 저장소에 올린 뒤, 워크시트에 `![설명](파일이름.jpg)`처럼 적어 연결합니다. 파일 이름은 영문 소문자로 씁니다.
6. Claude에 워크시트를 붙여 넣을 때는 편집 화면의 글을 그대로 복사합니다. Claude에게 결과를 받을 때 "마크다운 표로 줘"라고 하면 그대로 붙여 넣기 쉽습니다.

이 저장소는 끝까지 **Private**으로 둡니다. 배포는 A-6에서 따로 만드는 공개 저장소로만 합니다.

# Windows 사용자 메모

교재와 가이드는 Mac 키와 Mac 화면을 먼저 적은 곳이 많습니다. Windows 노트북을 쓰는 분은 4일 동안 만나는 차이를 이 한 쪽에서 찾으세요. 각 항목 끝의 가이드가 그 조작을 실제로 쓰는 곳입니다.

기준은 Windows 11 한국어판입니다. 메뉴 이름이 화면과 조금 다르면 괄호 안의 다른 이름도 찾아보세요.

## 1. 단축키 대응표

Mac의 `Cmd`는 Windows의 `Ctrl`, Mac의 `Option`은 Windows의 `Alt`로 바꿔 누르면 대부분 맞습니다. 그렇지 않은 키도 있으니 아래 표를 보세요.

|---|---|---|---|
| 복사 · 붙여 넣기 | `Cmd+C` · `Cmd+V` | `Ctrl+C` · `Ctrl+V` | 「[GitHub 워크시트 저장소 가이드](../guides/github-worksheet-repo-guide.md)」, 「[Stitch 시작 가이드](../guides/stitch-start-guide.md)」 |
| 모두 고르기 | `Cmd+A` | `Ctrl+A` | 「[화면 흐름 순서표 작성 가이드](../guides/screen-flow-guide.md)」, 「[Stitch 시작 가이드](../guides/stitch-start-guide.md)」 |
| 찾기 | `Cmd+F` | `Ctrl+F` | 「[Claude Code 프로토타이핑 따라 하기](../guides/claude-code-prototyping-guide.md)」, 「[배포 전 점검과 정적 배포 가이드](../guides/pre-deploy-check-guide.md)」 |

| 새 폴더 | `Cmd+Shift+N` (Finder) | `Ctrl+Shift+N` (파일 탐색기) | 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](../guides/claude-code-install-guide.md)」 |

| 시크릿 창 | `Cmd+Shift+N` | `Ctrl+Shift+N` | 「[GitHub Pages 정적 배포 가이드](../guides/github-pages-deploy-guide.md)」 |

### 확장자 보이기

Windows는 처음에 `.html`, `.md`, `.csv` 같은 확장자(파일 이름 끝의 형식 표시)를 숨깁니다. 수업 전에 한 번 켜 두세요.

1. 파일 탐색기를 엽니다.
2. 위쪽 **보기 → 표시 → 파일 이름 확장명**을 눌러 체크합니다. 화면에 따라 "파일 확장명"으로 보일 수 있습니다.

켜 두지 않으면 `DESIGN-neat-basic.md.txt`나 `index.html.html`처럼 확장자가 두 번 붙은 것을 알아채기 어렵습니다. 쓰는 곳: 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](../guides/claude-code-install-guide.md)」, 「[디자인 쇼핑처 둘러보기 가이드](../guides/design-shopping-guide.md)」, 「[배포 전 점검과 정적 배포 가이드](../guides/pre-deploy-check-guide.md)」

### 숨겨진 항목 보기

디자인 스킬은 작업 폴더 안의 `.claude` 폴더에 저장됩니다. Windows에서는 점으로 시작하는 폴더도 보통 그대로 보입니다. 보이지 않으면 이렇게 켭니다.

1. 파일 탐색기를 엽니다.
2. **보기 → 표시 → 숨겨진 항목**을 눌러 체크합니다.

폴더를 직접 열지 않고 Claude Code에 파일 목록을 물어봐도 됩니다. 쓰는 곳: 「[디자인 스킬 가져오기 가이드](../guides/design-skill-guide.md)」

### 복제한 뒤 이름 고치기

큰 변경 전에 남기는 복사본은 `<원래 파일 이름>-before-<다음 작업>` 형식으로 이름을 붙입니다. Windows에는 Mac의 `Cmd+D` 같은 복제 키가 없어서 복사와 붙여 넣기를 씁니다.

1. 파일 탐색기에서 파일을 고르고 `Ctrl+C`, `Ctrl+V`를 누릅니다.
2. 같은 폴더에 `- 복사본`이 붙은 파일이 생깁니다. 예) `prototype-final - 복사본.html`
3. 그 파일을 고르고 `F2`를 누릅니다. 확장자를 보이게 켜 두었다면 `.html` 앞부분만 선택됩니다.
4. 이름을 `prototype-final-before-deploy.html`처럼 고칩니다. 띄어쓰기와 `복사본`이 남지 않았는지 봅니다.

복사본은 작업 폴더 맨 위에 둡니다. Claude Code에 "○○ 파일을 ○○-before-○○ 이름으로 복사해 줘"라고 시켜도 됩니다. 쓰는 곳: 「[Claude Code 프로토타이핑 따라 하기](../guides/claude-code-prototyping-guide.md)」 5단계, 「[배포 전 점검과 정적 배포 가이드](../guides/pre-deploy-check-guide.md)」

### 경로 표기

가이드와 지시문 킷은 경로를 `axyourbody-prototype/data/`처럼 `/`로 씁니다. Windows 파일 탐색기 주소 표시줄에서는 같은 경로가 `\`로 나뉘어 보입니다.

| 가이드에 적힌 경로 | Windows 파일 탐색기에서 보이는 모습 (바탕화면에 만든 경우) |
|---|---|
| `axyourbody-prototype/data/` | `C:\Users\<사용자 이름>\Desktop\axyourbody-prototype\data` |
| `axyourbody-prototype/context/screen-flow.md` | `…\axyourbody-prototype\context\screen-flow.md` |

- 한국어 키보드와 일부 글꼴에서는 `\`가 `₩`로 보입니다. 같은 글자입니다.
- Claude Code에 경로를 쓸 때는 가이드처럼 `/`로 쓰면 됩니다. `@context/service-structure.md`처럼 작업 폴더 안의 경로만 씁니다.
- 작업 폴더 `axyourbody-prototype`은 바탕화면이나 문서 폴더에 만들고, Code 탭의 폴더 선택에서는 하위 폴더가 아니라 이 맨 위 폴더를 고릅니다.

쓰는 곳: 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](../guides/claude-code-install-guide.md)」, 「[Claude Code 프로토타이핑 따라 하기](../guides/claude-code-prototyping-guide.md)」

### HTML 파일을 브라우저로 열기

1. 파일 탐색기에서 `prototype-first-<테마이름>.html` 같은 HTML 파일을 두 번 누릅니다.
2. 브라우저가 아니라 메모장이나 다른 편집기가 열리면, 파일을 오른쪽 클릭하고 **연결 프로그램**에서 Chrome이나 Edge를 고릅니다.
3. 파일을 고친 뒤에는 브라우저에서 `F5`로 새로고침해야 바뀐 화면이 보입니다.

쓰는 곳: 「[Claude Code 프로토타이핑 따라 하기](../guides/claude-code-prototyping-guide.md)」 2단계

### 메모장으로 `.md` 파일 저장하기

메모장으로 `screen-flow.md` 같은 파일을 저장할 때는 저장 창에서 파일 형식을 **모든 파일**, 인코딩을 **UTF-8**로 고릅니다. 그래야 `.md.txt`가 되거나 한글이 깨지지 않습니다. 쓰는 곳: 「[화면 흐름 순서표 작성 가이드](../guides/screen-flow-guide.md)」

## 3. 설정

### 화면 전체를 회색조로 보기

색 없이도 구분되는지 볼 때 씁니다.

1. `Win+U`를 누르거나 **시작 → 설정 → 접근성**으로 갑니다.
2. **색 필터**를 누르고 색 필터 스위치를 켭니다.
3. 필터 목록에서 **회색조**(Grayscale)를 고릅니다.
4. 다 보면 스위치를 다시 끕니다.

쓰는 곳: 「[Stitch 시안 만들기 가이드](../guides/stitch-draft-guide.md)」 4단계, 「[파비콘·컬러 샘플 가이드](../guides/favicon-color-sample-guide.md)」 4단계

### 시크릿 창 열기

로그인하지 않은 다른 사람에게 보이는 화면을 확인할 때 씁니다.

| 브라우저 | Windows 단축키 | 창 이름 |
|---|---|---|
| Chrome | `Ctrl+Shift+N` | 시크릿 창 |
| Edge | `Ctrl+Shift+N` | InPrivate 창 |

Edge의 InPrivate(인프라이빗: 방문 기록과 로그인을 남기지 않는 창) 창이 가이드에서 말하는 시크릿 창과 같습니다. 쓰는 곳: 「[GitHub Pages 정적 배포 가이드](../guides/github-pages-deploy-guide.md)」, 「[GitHub 워크시트 저장소 가이드](../guides/github-worksheet-repo-guide.md)」, 「[발표·동료 리뷰 진행 가이드](../guides/presentation-review-guide.md)」

### 화면 캡처

1. `Win+Shift+S`를 누르면 화면이 어두워지고 캡처 도구 막대가 나옵니다.
2. **사각형**을 고르고 필요한 부분을 끌어서 잡습니다.
3. 잡은 이미지는 Figma나 Claude 입력창에 `Ctrl+V`로 바로 붙여 넣을 수 있습니다.
4. 파일이 필요하면 사진 폴더 안의 **스크린샷** 폴더를 봅니다. Windows 11은 캡처를 이 폴더에 자동으로 저장합니다. 화면 아래에 뜨는 알림을 눌러 캡처 도구에서 열고 저장해도 됩니다.

캡처 파일 이름은 영문 소문자로 고칩니다. 예) `reproduction-test.png`. 쓰는 곳: 「[Stitch 시작 가이드](../guides/stitch-start-guide.md)」, 「[나만의 DESIGN.md 만들기 가이드](../guides/my-own-design-md-guide.md)」

## 4. Claude 데스크톱 앱

### 설치 파일 고르기

Windows는 노트북 칩에 따라 받을 설치 파일이 다릅니다.

1. **설정 → 시스템 → 정보**에서 "시스템 종류"를 봅니다.
2. "ARM 기반 프로세서"라고 나오면 ARM64(에이알엠64: 휴대폰과 같은 계열의 칩을 쓴 노트북용)를 받습니다.
3. 그 밖에는 일반 x64용을 받습니다. claude.ai/download의 **Download for Windows**가 x64용이고, 그 아래에 ARM64 설치 파일이 있습니다.
4. 받은 설치 파일을 두 번 눌러 실행하고 안내대로 진행합니다. 설치가 끝나면 시작 메뉴에서 Claude를 엽니다.

쓰는 곳: 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](../guides/claude-code-install-guide.md)」 1번, 「[사전 안내 (Mac판 · Windows판)](../pre-course-notice.md)」 4번

### Windows에서만 만나는 일

| 이럴 때 | 이렇게 합니다 |
|---|---|
| 화면이 가이드와 다르거나 Code 탭이 안 보인다 | 앱 메뉴 **Help → Check for Updates…**로 앱 버전을 올리고 다시 엽니다 |
| 앱을 완전히 끄고 다시 열어야 한다 | 창만 닫지 말고 작업 관리자에서 Claude를 끝냅니다 |
| "Git is required"가 뜬다 | 먼저 앱 버전을 올립니다. 그래도 뜨면 Git for Windows(git-scm.com)를 설치하고 앱을 다시 엽니다 |
| "다른 설치가 진행 중" 오류가 난다 | 설치 파일을 오른쪽 클릭해 **관리자 권한으로 실행**합니다 |

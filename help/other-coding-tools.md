# 다른 AI 코딩 도구로 할 때 (OpenAI Codex · Cursor)

교재: 부록 A-5 · 쓰는 때: Day 3~4에 Claude Pro 사용 한도에 걸렸을 때

## 이 페이지에서 볼 것

Claude Pro 계정에는 일정 시간 동안 쓸 수 있는 양(사용 한도)이 있습니다. 실습 중에 한도를 다 써서 Claude Code를 한동안 쓸 수 없으면, 「[사전 안내 (Mac판 · Windows판)](../pre-course-notice.md)」 5번의 세 조건에 맞는 다른 회사의 AI 코딩 도구로 이어서 작업해도 됩니다. 이 페이지는 Claude Code에서 하던 조작이 OpenAI Codex와 Cursor에서는 무엇인지 한 표로 보여 줍니다.

**그대로인 것**

- 작업 폴더 `axyourbody-prototype`과 그 안의 파일 이름
- [지시문 킷](../kits/claude-code-prompts.md)의 지시문. 내용은 고치지 않고 그대로 씁니다
- 지시 → 결과 → 확인 → 수정 순서, 큰 변경 전 복사본 만들기
- 워크시트 문서 「테마별로 만든 첫 프로토타입과 버전 기록」 쓰는 법

**도구에 맞출 것**

- 폴더 여는 메뉴, 파일을 가리키는 방법(`@` 표기), 허락을 묻는 방식, 되돌리는 버튼

두 도구의 계정과 요금은 각 회사 안내를 따릅니다. 설치는 각 회사 누리집의 내려받기 안내를 봅니다.

## 어느 화면을 쓰나

- **OpenAI Codex**: 지금은 **ChatGPT 데스크톱 앱**(macOS · Windows) 안에서 씁니다. chatgpt.com/download에서 앱을 받아 로그인하고, 새 대화에서 **Codex**를 고릅니다. Codex에는 명령어를 치는 터미널판(CLI)과 코드 편집기에 붙이는 확장 기능도 있지만, 이 수업에서는 터미널이 필요 없는 데스크톱 앱을 씁니다.
- **Cursor**: Cursor 자체가 데스크톱 앱(macOS · Windows)입니다. cursor.com에서 받아 설치하고 로그인합니다. 대화로 일을 시키는 곳은 **Agent**(에이전트: 파일을 읽고 고치는 AI 작업 창)입니다.

## 조작 대응표

| 하는 일 | Claude Code (Code 탭) | OpenAI Codex (ChatGPT 데스크톱 앱) | Cursor |
|---|---|---|---|
| 작업 폴더 열기 | 입력창 아래 **환경 선택**에서 Local, **폴더 선택**에서 `axyourbody-prototype` | Codex를 고른 뒤 폴더 열기(또는 프로젝트를 만들고 폴더 추가)로 `axyourbody-prototype`을 고릅니다 | 앱을 열고 폴더를 고릅니다. 편집기 화면에서는 **File → Open Folder**. 그다음 `Cmd+I`(Windows `Ctrl+I`)로 Agent를 엽니다 |
| 파일을 가리키기 (`@`) | `@context/service-structure.md`처럼 `@`를 치고 후보에서 고릅니다 | 입력창에 `@`를 쳐서 파일 후보가 뜨면 고릅니다. 안 뜨면 "context 폴더의 service-structure.md 파일"처럼 경로를 글로 씁니다 | `@`를 치면 파일·폴더 후보가 뜹니다. `@context/service-structure.md`처럼 Claude Code와 같게 씁니다 |
| 파일 고치기 전 허락 / 자동 모드 | **모드 선택**: Manual(고치기 전에 묻기) · Accept edits(편집 자동 승인) · Auto(자동) | 입력창 아래 권한 선택에서 **Ask for approval**을 고릅니다. 작업 폴더 안의 파일은 묻지 않고 고치고, 폴더 밖 파일이나 인터넷을 쓸 때 묻습니다. **Full access**는 고르지 않습니다 | 파일 편집은 바로 적용되고, 바뀐 부분 보기(diff view)로 확인합니다. 고치기 전에 계획만 받으려면 입력창에서 `Shift+Tab`으로 **Plan Mode**를 켭니다. 명령 실행 허락은 **Settings → Agents → Approvals & Execution**에서 정하며, **Run Everything**은 고르지 않습니다 |
| 스킬 저장해 다시 쓰기 | 작업 폴더 안 `.claude/skills/<스킬이름>/SKILL.md`에 저장하고, 입력창 맨 앞에 `/<스킬이름>` | 지시문을 `design/skill-<스킬이름>.md`로 저장하게 한 뒤, "design/skill-<스킬이름>.md 의 지시를 따라 {영역 이름}에 적용해 줘"라고 가리킵니다 | Codex와 같은 `design/skill-<스킬이름>.md` 방법을 씁니다 |
| 만든 HTML을 브라우저로 열어 보기 | 파일 탐색기(Finder)에서 더블클릭, 고친 뒤에는 새로고침(`Cmd+R` / `F5`) | 같습니다 | 같습니다 |
| 되돌리기 | 큰 변경 전 복사본 `<원래 파일 이름>-before-<다음 작업>`을 만들고, 망가지면 "복사본과 똑같은 내용으로 되돌려 줘" | Claude Code와 같은 복사본 방법을 씁니다 | 복사본 방법이 기본입니다. 대화 기록의 **Restore Checkpoint**(체크포인트 되돌리기: 에이전트가 고치기 전 상태로 파일을 되돌림)도 쓸 수 있습니다 |
| 사용 한도 확인 | 입력창 아래 줄의 사용량 표시(동그라미) | 앱의 설정이나 계정 화면에서 봅니다. 위치는 앱 버전마다 다릅니다 | Cursor 설정이나 cursor.com 계정 대시보드의 사용량 화면에서 봅니다 |

**허락 방식이 다를 때.** Codex와 Cursor는 작업 폴더 안의 파일을 하나하나 묻지 않고 고칠 수 있습니다. Claude Code의 Manual처럼 먼저 보고 싶으면 지시문 끝에 "무엇을 바꿀지 목록으로 먼저 보여 주고, 제가 승인하면 고쳐 주세요."를 붙입니다. 어느 도구든 작업 폴더 밖 수정이나 설치 명령은 거절합니다.

**스킬을 쓸 때.** 디자인 스킬 저장과 적용은 「[디자인 스킬 가져오기 가이드](../guides/design-skill-guide.md)」 8번 「다른 회사의 AI 코딩 도구를 쓸 때」를 따릅니다. 안전하게 가져오는 규칙(먼저 읽기, 작업 폴더 안에만 저장, 설치 명령 거절)은 같습니다.

## 바꾸는 순서

1. 지금 고치던 파일의 복사본을 만듭니다. 예) `prototype-merged.html` → `prototype-merged-before-<다음 작업>.html`
2. Claude Code의 대화를 끝내고, 새 도구에서 같은 작업 폴더를 엽니다.
3. "이 폴더에 무엇이 있는지 알려 줘"로 같은 폴더가 열렸는지 확인합니다.
4. 새 도구에 앞 내용을 읽힙니다(아래 첫 항목).
5. 하던 단계의 지시문부터 이어서 보냅니다.

## 바꿔 쓸 때 주의

- **새 도구는 앞 대화를 모릅니다.** 첫 지시로 `context/service-structure.md`, `context/screen-flow.md`, 쓰고 있는 `design/DESIGN-<테마이름>.md`, 지금 고치던 프로토타입 파일을 가리키고 "이 파일들을 먼저 읽고, 이해한 내용을 다섯 줄로 요약해 주세요. 파일은 아직 고치지 마세요."라고 보냅니다. 요약이 맞으면 하던 단계로 넘어갑니다.
- **같은 파일을 두 도구로 동시에 고치지 않습니다.** 한쪽이 고치는 동안 다른 쪽이 같은 파일을 고치면 한쪽 변경이 사라질 수 있습니다. 한 번에 한 도구만 씁니다.
- **줄 번호는 다시 받습니다.** 줄 범위로 지시하기 전에 새 도구에서도 영역 지도를 새로 받습니다(「[여러 버전 통합 가이드](../guides/version-merge-guide.md)」 5단계).
- **결과는 작업 폴더 맨 위에 한 파일로 받습니다.** 새 폴더(예: `src`)를 만들거나 외부 라이브러리를 설치하려 하면 「[Claude Code 프로토타이핑 따라 하기](../guides/claude-code-prototyping-guide.md)」 맨 아래 「다른 도구를 쓸 때 달라지는 점」의 문장으로 다시 지시합니다.
- **파일 이름 규칙은 같습니다.** 도구가 다른 이름(예: `index.html`, `-backup`, 날짜 붙이기)으로 저장하면 교재의 파일 이름으로 바꾸게 합니다.
- **버전 기록에 도구를 적습니다.** 「테마별로 만든 첫 프로토타입과 버전 기록」의 관찰 메모에 "{단계}부터 {도구 이름} 사용"처럼 한 줄 적습니다. 칸 쓰는 법은 그대로입니다.
- **한도가 풀리면 돌아와도 됩니다.** 파일은 작업 폴더에 그대로 있습니다. Claude Code로 돌아올 때도 새 대화로 시작하고 첫 항목처럼 파일을 다시 읽힙니다.

## 막혔을 때

- **새 도구가 파일을 못 찾는다** → 작업 폴더를 한 단계 위나 아래로 연 것입니다. `axyourbody-prototype` 맨 위 폴더를 다시 엽니다.
- **Codex에서 권한 선택이 안 보이거나 Ask for approval이 없다** → 앱을 최신 버전으로 올리고 다시 엽니다. 그래도 없으면 지시문 끝에 "제가 승인하기 전에는 고치지 마세요."를 붙여 씁니다.
- **Cursor가 한 번에 여러 파일을 고쳤다** → 대화 기록에서 Restore Checkpoint로 되돌리거나, 복사본으로 되돌린 뒤 범위를 좁혀 다시 지시합니다.
- **도구가 터미널 명령을 실행하겠다고 한다** → 이번 실습에는 필요 없습니다. 거절하고 "명령은 실행하지 말고, 작업 폴더의 파일만 읽고 고쳐 주세요."라고 지시합니다.

설치와 Code 탭 조작은 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](../guides/claude-code-install-guide.md)」를 봅니다.

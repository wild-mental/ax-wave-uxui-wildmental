# 사례 분석 시트 가이드

교재: 1.2절 UX와 UI는 무엇이 다른가 · 쓰는 곳: 문서 템플릿 `worksheet.md`의 「익숙한 서비스의 사용 경험을 과업 관점으로 뜯어본 사례 분석 시트」

## 이 가이드에서 볼 것

사례 분석 시트는 Day 1에 처음 채우는 워크시트입니다. 이 가이드는 분석할 서비스를 고르는 기준, `worksheet.md`의 일곱 칸에 쓰는 요령, 자주 하는 실수와 체크리스트 확인 방법을 다룹니다. 칸마다 무엇을 쓰는지는 교재 1.2절의 [실습 안내] 표와 이서연 예제 표를 봅니다.

## 분석할 서비스 고르기

- **지금 바로 열 수 있는 서비스**를 고릅니다. 교재 1.2절의 [실습 안내]처럼 화면을 열고 과업을 직접 해 보며 적어야 단계가 빠지지 않습니다.
- **5~10분 안에 끝나는 과업 하나**가 있는 서비스가 좋습니다. 입력하거나 고르는 순간이 있는 과업(기록하기, 예약하기, 찾아서 저장하기)이 단계를 나누기 쉽습니다.
- 건강·운동 앱이 없다면 평소 쓰는 다른 앱도 괜찮습니다. 단계를 나누는 연습은 같습니다. 다만 ⑦ 교훈은 AX YOUR BODY에 가져갈 수 있게 씁니다.
- 내 실제 기록이 화면에 보이는 앱이라면, 아래 "화면 사진 넣기"의 주의를 먼저 읽습니다.

## 템플릿에서 쓰는 곳

`worksheet.md`를 열고 연필 아이콘을 눌러 편집합니다(부록 A-2). 「익숙한 서비스의 사용 경험을 과업 관점으로 뜯어본 사례 분석 시트」 제목 아래, ①~⑦ 일곱 줄짜리 표의 오른쪽 "작성" 칸에 씁니다.

- **칸 안에서는 `Enter`를 누르지 않습니다.** 표가 끊어집니다. ③ 단계는 템플릿에 있는 대로 `1) … 2) … 3) …`처럼 한 줄에 이어 씁니다.
- **④·⑤는 단계 번호로 시작합니다.** 예) `3) 연장 단추가 목록 맨 아래에 있어 세 번 스크롤한 뒤 찾는다`. 여러 개면 ` · `로 나눕니다.
- **⑥은 ④·⑤와 짝이 보이게 씁니다.** 예) `3) 막힘 → 외우게 하지 말고 보고 고르게 한다 · 5) 잘 도움 → 지금 무슨 일이 일어나는지 보여 준다`. 휴리스틱은 교재 1.2절 표의 "쉬운 말"로 적습니다.
- 칸 안에는 세로 막대 `|`를 쓰지 않습니다. 표 칸의 경계로 읽혀 표가 깨집니다.
- 저장 전에 미리 보기(Preview) 탭에서 표가 제대로 보이는지 보고 "Commit changes"로 저장합니다.

**화면 사진 넣기(선택).** 단계 화면을 캡처해 두면 짝에게 설명하기 쉽습니다. 내 워크시트 저장소에 Add file → Upload files로 올리고, 표 아래에 `![3단계 양 입력 화면](case-step3.jpg)`처럼 적습니다. 올리기 전에 내 이름·계정·실제 신체 수치·다른 사람의 정보가 화면에 보이지 않는지 확인하고, 보이면 가린 뒤 올립니다.

## 자주 하는 실수와 고친 예

- **하려는 일이 넓다** (도서관 앱 예: "책 관리하기") → 끝이 분명한 한 문장으로 좁힙니다: "빌린 책의 반납일을 일주일 연장한다."
- **단계를 화면 이름으로 적었다** ("마이페이지", "대출 목록") → 사용자의 행동으로 적습니다: "마이페이지에서 대출 목록을 연다", "연장할 책을 고른다".
- **단계를 너무 잘게 나눴다** (스크롤 한 번, 손가락 한 번마다 한 단계) → 화면이 바뀌거나 사용자가 결정·입력하는 순간만 단계로 셉니다(교재 1.2절 "과업 관점으로 역분석하기"). 3~7개가 되도록 합칩니다.
- **평가하는 말을 썼다** ("연장 메뉴가 최악이다", "UI가 불편함") → 관찰한 사실로 바꿉니다: "4) 연장을 누른 뒤 아무 표시가 없어 한 번 더 눌렀다."
- **교훈이 누구에게나 맞는 말이다** ("쉽게 만들어야 한다") → 누구의 어떤 과업에 무엇을 가져갈지 씁니다: "자주 하는 입력은 한 화면 안에서 끝나게 한다."

## 완료 기준 체크리스트 확인 방법

| 체크리스트 항목 | 이렇게 확인합니다 |
|---|---|
| 하려는 일을 끝이 분명한 한 문장으로 썼다 | ② 칸이 마침표 하나로 끝나는 한 문장이고, "언제 끝났다고 말할 수 있는지"가 문장 안에 보입니다 |
| 단계를 3~7개로 나눴다 | ③ 칸의 `1)`, `2)` … 번호가 3개 이상 7개 이하이고, 각 단계가 행동(동사)으로 끝납니다 |
| 막히는 지점과 잘 돕는 지점을 각각 1개 이상 찾았다 | ④와 ⑤ 칸이 모두 단계 번호로 시작하는 항목을 하나 이상 가지고 있습니다 |
| 막히는 지점에 관련 휴리스틱을 붙였다 | ④의 단계 번호마다 ⑥에 같은 번호가 있고, 휴리스틱 이름이 교재 1.2절 표의 쉬운 말과 같습니다 |
| 평가하는 말 대신 관찰한 사실로 썼다 | "최악", "구리다", "별로" 같은 낱말을 찾아봅니다. 남아 있으면 "몇 단계에서 무엇이 어떻게 됐는지"로 바꿉니다 |

## 막혔을 때

- 단계가 3개도 안 나오면 과업이 너무 작은 것입니다. 과업을 하나 키우거나("반납일 확인" → "반납일 연장") 다른 과업을 고릅니다.
- 휴리스틱을 고르기 어려우면 교재 1.2절 휴리스틱 표의 "어겨졌을 때" 칸을 내 막힌 단계와 하나씩 견줘 봅니다.
- 메모를 Claude로 정리할 때는 교재 1.2절의 지시문을 씁니다(조작은 부록 A-1, 「Claude 시작 가이드」). 결과에 내가 하지 않은 단계가 있으면 이렇게 다시 묻습니다: "내 메모에 없는 단계는 지우고, 빠진 것 같은 곳은 질문으로만 남겨 줘."
- 이 시트를 끝냈으면 「과업·불편 목록 가이드」로 넘어갑니다.

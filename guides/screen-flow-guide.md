# 화면 흐름 순서표 작성 가이드

교재: Part 3 · 3.2 흐름 순서표와 화면 목록 확정하기 · 쓰는 곳: Figma 템플릿의 「과업별 화면 흐름 순서표와 화면 목록」 페이지 → 3.6에서 작업 폴더의 `context/screen-flow.md`

## 이 가이드에서 볼 것

이 워크시트는 Figma에서 쓰고, 3.6에서 Claude Code가 읽는 글 파일로 옮깁니다. 이 가이드는 Figma 페이지를 채우는 조작, 내 프로필 CSV에서 빠진 날과 급변한 날을 **찾는 방법**, `context/screen-flow.md`로 옮기는 방법을 다룹니다. 칸마다 무엇을 쓰는지는 교재 3.2의 [실습 안내] 표와 김도현 예제를 봅니다.

## 템플릿에서 쓰는 곳

### Figma 페이지 채우기

1. 내 Figma 파일(`4-1_이름_프로필ID`)에서 왼쪽 페이지 목록의 「과업별 화면 흐름 순서표와 화면 목록」을 엽니다.
2. 영역은 위에서부터 핵심 과업 · 기본 흐름 · 갈림길 · 화면 목록 · 상태 화면 목록입니다. 영역 이름이 적힌 상자는 지우지 않고, 글 상자를 두 번 눌러 내용만 고칩니다.
3. 기본 흐름과 갈림길은 화면 이름과 화살표(→)만 씁니다. 화면 이름 상자를 쓰는 영역이면 상자를 `Cmd+D`(Windows `Ctrl+D`)로 복제해 이름을 바꾸고 화살표로 잇습니다. 화살표 글자는 템플릿에 있는 →를 복사해 쓰면 편합니다.
4. 화면 목록과 상태 화면 목록은 가로 한 줄을 이루는 상자들을 함께 골라(끌어서 범위 잡기 또는 `Shift`+클릭) 복제한 뒤 아래로 옮겨 행을 늘립니다.

### 상태 화면의 근거 찾기: 내 프로필 CSV 읽는 법

결과를 미리 알려 주지 않습니다. 아래 방법으로 여러분이 직접 찾습니다.

1. **사본으로 엽니다.** 내 프로필의 CSV 네 개(`body.csv`, `workout.csv`, `meal.csv`, `sleep.csv`)를 표 계산 프로그램(엑셀, Google 스프레드시트 등)으로 엽니다. 여는 방법과 열 이름의 뜻은 「과업·불편 목록 가이드」를 봅니다. 정렬하거나 열을 더하려면 사본에서 합니다. 작업 폴더 `data`의 원본은 Claude Code가 읽을 파일이므로 고쳐 저장하지 않습니다.
2. **날짜순으로 정렬합니다.** 날짜 열을 기준으로 오름차순 정렬합니다. 정렬 창에서 첫 줄을 머리글(열 이름)로 지정하는 선택 상자를 켜서 열 이름이 함께 섞이지 않게 합니다.
3. **빠진 날을 찾습니다.** 먼저 교재 「4주치 기록 데이터셋 안내」 표에서 파일마다 측정 주기를 봅니다. 매일 쓰는 파일은 날짜가 하루라도 건너뛰는 곳, 주 1~2회 쓰는 파일은 간격이 평소보다 길어지는 곳, 운동한 날만 쓰는 파일은 쉬는 날일 수 있으니 다른 파일과 함께 봅니다. 끼니 단위로 쓰는 파일은 날짜별 줄 수가 갑자기 줄어든 날을 봅니다. 날짜 옆 빈 열에 `=A3-A2`처럼 앞 줄과의 날짜 차이를 계산하면 건너뛴 곳이 숫자로 드러납니다(칸 주소는 내 파일에 맞게 바꿉니다). 같은 날짜가 여러 줄인 파일에서는 0이 나온 줄을 건너뜁니다.
4. **여러 파일을 겹쳐 봅니다.** 한 파일에서 빈 날을 찾으면 같은 날짜를 나머지 세 파일에서도 찾아봅니다. 여러 파일이 함께 비는 구간은 빈 상태 화면의 근거 후보입니다.
5. **급변한 날을 찾습니다.** 숫자 열 옆 빈 열에 앞 값과의 차이(`=B3-B2`)를 계산하고, 차이가 유난히 큰 줄에 표시합니다. 숫자 열을 골라 꺾은선 차트를 넣으면 혼자 솟거나 꺼진 점이 눈에 띕니다.
6. **이유를 읽습니다.** 표시한 줄마다 `body.csv`의 측정 조건 열(`measure_condition`)처럼 글이 적힌 칸을 읽습니다. 앞뒤 며칠의 다른 파일(수면, 운동)도 봅니다. 혼자 튀었다가 돌아오는 값인지, 계획된 변화(교재 3.2의 회복 주간 설명)처럼 며칠 이어지는 변화인지 구분합니다. 계획된 변화는 경고가 아니라 설명이 필요한 경우입니다.
7. **근거 데이터 칸에 옮겨 적습니다.** `파일 이름 · 날짜 · 값` 순서로 씁니다. 빈 날은 값 대신 "기록 없음", 측정 조건이 다르면 그 조건도 함께 적습니다. 예) `{파일 이름} · {날짜} · {값}({측정 조건})`

### `context/screen-flow.md`로 옮기기 (3.6, 부록 A-5)

1. Figma 글 상자를 두 번 눌러 글자 편집 상태로 만든 뒤 `Cmd+A`(Windows `Ctrl+A`), `Cmd+C`(`Ctrl+C`)로 글만 복사합니다.
2. 파일은 아래 제목 순서로 만듭니다. 상태 화면을 더하는 지시문이 "상태 화면 목록"이라는 이름으로 이 부분을 찾으므로 제목 글자를 바꾸지 않습니다. 화면 목록과 상태 화면 목록은 Figma의 열 이름을 그대로 머리줄로 쓴 Markdown 표로 적습니다.

   ```text
   # 화면 흐름 순서표 — {프로필 이름}
   ## 핵심 과업
   ## 기본 흐름
   ## 갈림길
   ## 화면 목록
   ## 상태 화면 목록
   ```

3. 파일 만들기는 두 방법 중 하나를 씁니다. Claude Code 앱에서 작업 폴더를 연 상태로 "context 폴더에 screen-flow.md 파일을 만들고, 아래 글을 한 글자도 바꾸지 말고 그대로 저장해 줘."라고 쓴 뒤 글을 붙여 넣거나, 메모장(Windows)·텍스트 편집기(Mac)로 저장합니다. 메모장은 파일 형식을 "모든 파일", 인코딩을 UTF-8로 고릅니다. Mac 텍스트 편집기는 먼저 포맷 메뉴의 "일반 텍스트로 만들기"를 누르고, 저장할 때 `.txt`가 붙지 않게 확인합니다.

## 자주 하는 실수와 고친 예

- **흐름에 화면 모양을 적었다** (택배 앱 예: "큰 파란 버튼 누름 → 지도 화면") → 화면 이름만 남깁니다: "배송 조회 → 배송 지도".
- **용어 대조표에 없는 화면 이름을 썼다** → 용어 대조표에 먼저 행을 더한 뒤 그 이름을 씁니다.
- **근거 데이터를 뭉뚱그려 썼다** ("가끔 기록이 빠짐") → 파일 이름과 날짜를 적습니다. 날짜를 못 쓰면 아직 찾지 않은 것입니다.
- **계획된 변화를 이상치 경고로 적었다** → 보여 줄 것 칸에 경고 대신 "계획된 변화라는 설명"을 적습니다.
- **정렬한 CSV를 원본 위에 저장했다** → 원본 파일을 다시 받아 `data` 폴더에 넣고, 정렬은 사본에서 합니다.

## 완료 기준 체크리스트 확인 방법

- [ ] **핵심 과업 1개의 기본 흐름을 처음부터 끝까지 화면 이름으로 이었다** → 핵심 과업이 하나뿐인지, 흐름의 마지막 화면에서 과업이 끝나는지 소리 내 읽어 봅니다. 화면 수가 일곱 개를 넘지 않는지 셉니다.
- [ ] **갈림길이 있으면 조건과 함께 적었다** → "계획대로 안 되는 날"을 떠올려 흐름이 나뉘는 곳이 있는지 봅니다. 있다면 갈림길 줄에 [조건]과 다른 경로가 있는지 확인하고, 없으면 비워 둡니다.
- [ ] **화면마다 목적과 측정 지표 1개를 적었다** → 기본 흐름과 갈림길의 화면 이름이 모두 화면 목록에 있는지 짚고, 지표가 "누른 비율", "걸린 시간"처럼 셀 수 있는 것 하나인지 봅니다.
- [ ] **상태 화면 4종(빈·오류·로딩·이상치)을 적고, 빈 상태와 이상치에는 근거 데이터를 붙였다** → 빈 상태 · 오류 · 로딩 · 이상치가 한 줄씩 있는지, 빈 상태와 이상치 줄에 파일 이름과 날짜가 있는지 봅니다.
- [ ] **내용을 작업 폴더 `context/screen-flow.md`로 옮겼다** → 3.6에서 확인합니다. Claude Code에 "@context/screen-flow.md 의 제목만 순서대로 보여 줘"라고 물어 여섯 제목이 나오는지 봅니다.

## 막혔을 때

- 빠진 날과 급변을 찾는 감은 교재 Part 1의 "과업 단서는 어디에 있나"에 나오는 네 가지 무늬 표(빈칸 · 급변 · 리듬 · 거리)를 다시 보면 잡힙니다. Part 2에서 그린 여정 레인의 근거 날짜도 출발점이 됩니다.
- Claude의 도움을 받을 때는 교재 2-2 [실습 안내]의 지시문을 고쳐 쓰고, 해석은 빼고 위치만 묻습니다: "날짜가 건너뛴 곳과 앞뒤 값보다 크게 다른 줄을 파일 이름·날짜·값으로만 적어 줘. 이유는 짐작하지 마." 받은 목록은 CSV에서 직접 확인한 뒤 적습니다(부록 A-1).
- Figma 조작은 부록 A-3, 파일 옮기기와 Claude Code는 부록 A-5와 「Claude Code 프로토타이핑 따라 하기」를 봅니다.
- 화면 이름이 막히면 「용어 대조표 작성 가이드」와 「진입점 선택표 작성 가이드」로 돌아갑니다.

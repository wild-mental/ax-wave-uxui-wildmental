## 목차 초안

1. Google 계정으로 stitch.withgoogle.com 로그인
2. 새 프로젝트, 플랫폼은 웹(데스크톱)
3. 지시문 킷의 「Stitch 테마별 시안 생성 지시문」 붙여 넣기
4. DESIGN.md 내용 붙여 넣기 또는 파일 첨부
5. 변경 지시는 한 번에 한 가지
6. 시안을 이미지로 내보내기 → Figma 시안 비교표에 붙이기
7. 막혔을 때 (생성 한도, 첨부 실패 등)
8. 화면 확인 날짜

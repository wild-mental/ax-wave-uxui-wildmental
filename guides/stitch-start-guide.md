# Stitch 시작 가이드

교재: 부록 A-4 Google Stitch · 쓰는 날: Day 3 (Day 4 재현 시험에서 한 번 더) · 쓰는 곳: Stitch에서 만든 시안 이미지 → Figma 템플릿의 「Google Stitch로 만든 테마별 화면 시안 비교표」 페이지

## 이 가이드에서 볼 것

- Google Stitch는 글로 설명한 화면을 시안 이미지로 그려 주는 웹 도구입니다. 설치 없이 브라우저에서 쓰고, Mac과 Windows 화면이 같습니다.
- 이 가이드는 **조작만** 다룹니다: 로그인 → 새 프로젝트 → 지시문과 DESIGN.md 넣기 → 변경 지시 → 이미지로 꺼내 Figma에 붙이기.
- 테마별로 시안을 뽑아 비교하는 실습 흐름은 「[Stitch 시안 만들기 가이드](stitch-draft-guide.md)」와 교재 3.5절을 봅니다.

## 1. 로그인하기

1. 브라우저 주소창에 `stitch.withgoogle.com`을 입력합니다. 주소가 `stitch.google.com`으로 바뀌어 열려도 같은 곳입니다.
2. 오른쪽 위의 로그인 단추를 누르고 Google 계정을 고릅니다. 처음이면 이용 약관 동의 화면이 나옵니다.
3. 가운데에 큰 입력창이 있는 첫 화면이 보이면 준비가 끝난 것입니다.

## 2. 새 프로젝트 만들고 웹으로 고르기

1. 첫 화면의 입력창이 새 프로젝트의 시작입니다. 이미 다른 프로젝트 안에 있다면 왼쪽 위 Stitch 로고나 프로젝트 목록에서 새 프로젝트를 엽니다.
2. 입력창 근처의 기기 선택에서 **Web**(웹, 데스크톱 너비)을 고릅니다. **App**은 휴대폰 화면입니다.
3. 모델(생성 방식) 선택이 보이면 기본값 그대로 둡니다.

> [캡처 예정] 공통: 입력창 아래 App · Web 선택, 모델 선택, 첨부(+) 아이콘 위치

## 3. 지시문과 DESIGN.md 넣기

1. [지시문 킷](../kits/claude-code-prompts.md)의 「Stitch 테마별 시안 생성 지시문」을 복사해 입력창에 붙여 넣고, `{ }` 부분을 내 내용으로 바꿉니다.
2. **DESIGN.md는 내용을 붙여 넣는 방법을 먼저 씁니다.** 3.4절에서 내려받아 저장해 둔 `DESIGN-{테마이름}.md`(작업 폴더로 옮긴 뒤라면 `design` 폴더 안)를 텍스트 편집기(Mac 텍스트 편집기, Windows 메모장)로 열어 `Cmd+A` → `Cmd+C`(Windows `Ctrl+A` → `Ctrl+C`)로 복사하고, 지시문의 `[디자인]` 줄을 "아래 DESIGN.md의 규칙만 따라 주세요. 문서에 없는 색은 쓰지 마세요."로 바꾼 뒤 지시문 맨 끝에 붙여 넣습니다.
3. 파일로 첨부하고 싶다면 입력창의 첨부(**+** 또는 클립·이미지 아이콘)를 눌러 `.md` 파일을 고릅니다. 고를 수 없게 막혀 있으면 2번 방법으로 돌아갑니다. 첨부하면 `[디자인]` 줄의 `{DESIGN-테마이름.md}`에 그 파일 이름을 적습니다. 첫 시안은 붙여 넣기로 결과를 확인하고, 첨부가 되는 것을 확인했다면 두 번째 테마부터 첨부로 넘어가도 됩니다(「[Stitch 시안 만들기 가이드](stitch-draft-guide.md)」 준비 4번).
4. 보내고 1~2분 기다리면 오른쪽 캔버스에 화면 시안이 나타납니다.

## 4. 변경 지시는 한 번에 한 가지

1. 캔버스에서 고칠 화면을 한 번 눌러 고른 상태로 둡니다. 고르지 않으면 다른 화면이 바뀌거나 새 화면이 생길 수 있습니다.
2. 입력창에 한 가지만 씁니다. 예) "맨 위 요약 숫자를 더 크게 해 줘." 색과 배치를 한꺼번에 바꾸라고 하지 않습니다.
3. 모바일 화면이 필요하면 같은 프로젝트에서 "같은 화면을 모바일로도 만들어 줘"라고 따로 요청합니다.

시안 생성에는 계정마다 한도가 있습니다. 한 테마에서 끝없이 다듬지 말고, 비교에 필요한 만큼만 고칩니다(교재 3.5절).

## 5. 이미지로 꺼내 Figma 비교표에 붙이기

1. 캔버스에서 시안 하나를 고르고, 그 화면의 메뉴(**⋯** 또는 **More**)를 엽니다.
2. **Export**(내보내기)나 다운로드 항목에 이미지(PNG) 저장이 있으면 그것으로 내려받습니다.
3. 이미지 저장 항목이 없으면 화면 캡처로 이미지를 만듭니다. 시안을 화면에 크게 띄운 뒤 아래 단축키로 시안 부분만 잡습니다.

| 조작 | Mac | Windows |
|---|---|---|
| 일부만 캡처해 바로 복사 | `Ctrl+Shift+Cmd+4` → 끌어서 범위 잡기 | `Win+Shift+S` → 사각형 캡처 → 끌어서 범위 잡기 |
| 일부만 캡처해 파일로 저장 | `Shift+Cmd+4` → 바탕화면에 저장 | `Win+Shift+S` → 사각형으로 고르면 사진 → 스크린샷 폴더에 저장됨 |

4. 내 Figma 파일의 「Google Stitch로 만든 테마별 화면 시안 비교표」 페이지를 열고, 해당 테마 줄의 시안 화면 칸에 `Cmd+V`(Windows `Ctrl+V`)로 붙여 넣거나 이미지 파일을 끌어다 놓습니다. 테마 이름과 화면 이름을 이미지 옆에 적어 둡니다.

> [캡처 예정] 공통: 시안의 메뉴를 열어 Export 항목이 보이는 화면

## 자주 하는 실수와 고친 예

- **App(휴대폰)으로 만들었다** → 같은 프로젝트에서 "같은 화면을 웹 데스크톱 너비로 다시 만들어 줘"라고 하거나, 새 프로젝트를 Web으로 엽니다.
- **DESIGN.md를 넣지 않고 지시문만 보냈다** (색과 글꼴이 테마와 상관없이 나옴) → 지시문 맨 끝에 DESIGN.md 내용이 붙었는지(첨부했다면 파일이 첨부됐는지) 확인하고 다시 보냅니다.
- **두 테마를 한 지시문에 함께 넣었다** → 테마마다 따로 보냅니다. 테마를 바꿀 때는 DESIGN.md 내용만 바꿔 붙여 넣습니다.
- **변경 지시 서너 가지를 한 번에 줬다** → 결과가 엉키면 마지막으로 마음에 들었던 시안을 기준으로 한 가지씩 다시 지시합니다.
- **화면 전체를 캡처해 브라우저 주소창과 탭까지 들어갔다** → 시안 부분만 다시 캡처합니다. 다른 탭 이름이나 알림이 보이면 비교표에 붙이지 않습니다.

## 제대로 됐는지 확인

- [ ] **로그인했다** → Stitch 첫 화면 오른쪽 위에 내 Google 계정 사진이나 머리글자가 보입니다.
- [ ] **웹 시안이 나왔다** → 캔버스의 시안이 가로로 넓은 데스크톱 화면입니다.
- [ ] **DESIGN.md를 따랐다** → 시안의 바탕색과 강조색이 DESIGN.md에 적힌 색과 비슷합니다.
- [ ] **Figma에 붙였다** → 비교표 페이지의 테마 줄마다 시안 이미지가 있고, 테마 이름이 적혀 있습니다.

## 막혔을 때

- **로그인이 안 되거나 "사용할 수 없다"고 나옵니다.** 회사·학교 Google 계정은 관리자가 막아 두었을 수 있습니다. 개인 Gmail 계정으로 다시 로그인합니다.
- **생성이 오래 걸리거나 멈췄습니다.** 2~3분 기다린 뒤 페이지를 새로 고칩니다. 만든 시안은 프로젝트에 남아 있습니다. 같은 지시를 여러 번 보내면 한도만 줄어듭니다.
- **한도를 다 썼다는 안내가 나옵니다.** 이미 만든 시안으로 비교를 마칩니다. 시안이 모자라면 짝의 Stitch 화면을 함께 보고 비교하거나, 수업 중에 손을 들어 현장에서 도움을 받습니다.
- **DESIGN.md를 붙여 넣었더니 입력창이 너무 깁니다.** 그대로 보내도 됩니다. 보내지지 않으면 DESIGN.md에서 색 · 글꼴 · 부품 · 하지 말 것 항목만 남기고 붙여 넣습니다.

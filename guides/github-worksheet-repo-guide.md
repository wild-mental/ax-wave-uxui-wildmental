## 목차 초안

1. GitHub 계정 만들기 (아이디 고르기: Day 4 배포 주소에 들어감)
2. New repository → 이름 `axyourbody-worksheet` → 공개 범위 Private → Create repository
3. 자료실 저장소의 `worksheet-template/worksheet.md`에서 Copy raw file로 복사
4. 내 저장소에서 creating a new file → 파일 이름 `worksheet.md` → 붙여 넣기 → Commit changes
5. 강사 `wild-mental` 초대하기 (Settings → Collaborators → Add people)
6. `worksheet.md` 고치고 Commit changes로 저장하기
7. Preview로 표 확인, 체크리스트 `[x]` 표시
8. 표 행 늘리기와 칸 쓰기 규칙 (`|` 금지, 쉼표나 " · "로 나누기)
9. 이미지 올리고 연결하기 (저장소 맨 위, `![설명](파일이름.jpg)`)
10. Claude와 주고받기 (편집 화면 글 복사, "마크다운 표로 줘")
11. `my-own-DESIGN.md` 올리기와 Day 4 제출 링크 확인
12. 막혔을 때 (Public으로 만들었을 때 Change visibility, 초대가 안 보일 때 등)
13. 화면 확인 날짜

# GitHub 워크시트 저장소 가이드

교재: 부록 A-2 GitHub 워크시트 저장소 · 쓰는 날: Day 1~4 (계정과 저장소는 수업 전에) · 쓰는 곳: 내 비공개 저장소 `axyourbody-worksheet`의 `worksheet.md`

## 이 가이드에서 볼 것

- 워크시트 문서는 내 **Private**(비공개) 저장소 `axyourbody-worksheet` 하나에 4일 동안 씁니다. 강사 GitHub 아이디 `wild-mental`만 초대합니다.
- 교재 부록 A-2의 순서(처음 한 번 만들기 → 워크시트 쓰기)를 실제 화면의 버튼 위치로 따라갑니다.
- 모두 github.com 웹 화면에서 합니다. Mac과 Windows의 화면이 같고, 단축키만 다릅니다(Mac `Cmd` = Windows `Ctrl`).

자료실 저장소: `https://github.com/wild-mental/ax-wave-uxui-wildmental` · 워크시트 문서 원본: [`worksheet-template/worksheet.md`](https://github.com/wild-mental/ax-wave-uxui-wildmental/blob/main/worksheet-template/worksheet.md)

## 처음 한 번: 저장소 만들기

1. **계정 만들기.** github.com 오른쪽 위 **Sign up**에서 만듭니다. 아이디(Username)는 Day 4 배포 주소 `https://아이디.github.io/…`에 그대로 들어가므로 실명이 드러나지 않는 아이디를 고릅니다. 가입 메일의 인증 코드를 넣어야 가입이 끝납니다.
2. **새 저장소.** 로그인한 뒤 오른쪽 위 **+** 단추 → **New repository**를 누릅니다.
3. **이름과 공개 범위.** Repository name에 `axyourbody-worksheet`를 씁니다. 공개 범위(visibility) 선택에서 **Private**을 고릅니다. README 추가 같은 선택 항목은 건드리지 않고 **Create repository**를 누릅니다.

> [캡처 예정] 공통: New repository 화면에서 이름 칸과 Private 선택 위치

4. **원본 복사.** 새 탭에서 위의 워크시트 문서 원본 링크를 엽니다. 파일 내용 위쪽 막대 오른쪽의 **Copy raw file**(네모 두 개가 겹친 복사 아이콘)을 누릅니다. 화면에는 변화가 없어도 전체가 복사된 것입니다.

> [캡처 예정] 공통: worksheet.md 원본 화면의 Raw · Copy raw file · Download raw file 아이콘 위치

5. **파일 만들기.** 내 저장소 탭으로 돌아와 빈 저장소 안내 문구의 **creating a new file** 링크를 누릅니다. 위쪽 이름 칸에 `worksheet.md`를 쓰고, 아래 편집 칸을 한 번 누른 뒤 `Cmd+V`(Windows `Ctrl+V`)로 붙여 넣습니다.
6. **저장.** 오른쪽 위 **Commit changes...** → 뜨는 상자에서 **Commit changes**를 누릅니다.
7. **강사 초대.** 저장소 위쪽 탭의 **Settings** → 왼쪽 메뉴 Access 아래 **Collaborators** → **Add people**을 누릅니다. 검색 칸에 `wild-mental`을 쓰고, 목록에서 아이디가 정확히 `wild-mental`인 항목을 고른 뒤 **Add wild-mental to this repository**를 누릅니다. 비밀번호나 인증을 다시 물으면 입력합니다.

> [캡처 예정] 공통: Settings → Collaborators 화면의 Add people 단추와 초대 후 Pending invite 표시

초대한 뒤 목록에 `wild-mental`이 **Pending invite**(수락 대기)로 보이면 여러분이 할 일은 끝났습니다. 강사가 수락하면 대기 표시가 사라집니다.

## 워크시트 쓰기와 저장

1. 저장소 첫 화면에서 `worksheet.md`를 누르고, 파일 오른쪽 위의 연필 아이콘(**Edit this file**)을 누릅니다.
2. 칸을 채웁니다. 원하는 워크시트 제목은 `Cmd+F`(Windows `Ctrl+F`)로 찾습니다.
3. 편집 칸 위의 **Preview** 탭을 눌러 표가 칸에 맞게 보이는지 확인하고, **Edit** 탭으로 돌아와 고칩니다.
4. **Commit changes...** → **Commit changes**로 저장합니다. 저장하지 않고 탭을 닫으면 쓴 내용이 사라지므로, 한 워크시트를 마칠 때마다 저장합니다.

> [캡처 예정] 공통: 편집 화면의 Edit · Preview 탭과 Commit changes 단추 위치

### 표·체크리스트 쓰는 규칙 한눈에

| 하고 싶은 것 | 이렇게 |
|---|---|
| 체크 표시 | 편집 화면에서 `- [ ]`를 `- [x]`로 고칩니다. 파일 보기 화면에서는 눌러도 체크되지 않습니다 |
| 행 늘리기 | 빈 행 한 줄을 통째로 복사해 바로 아래에 붙입니다. 맨 위 제목 줄과 그 아래 구분선 줄은 건드리지 않습니다 |
| 한 칸에 여러 항목 | 쉼표(,)나 " · "로 나눕니다. 칸 안에서 `Enter`로 줄을 바꾸지 않습니다 |

### 이미지 올리고 연결하기

1. 저장소 첫 화면에서 **Add file → Upload files**를 누르고, 이미지를 끌어다 놓은 뒤 **Commit changes**를 누릅니다. 저장소 맨 위에 올립니다.
2. 파일 이름은 영문 소문자로 미리 바꿔 둡니다. 예) `erd-sketch.jpg`
3. `worksheet.md` 편집 화면의 해당 칸 아래에 `![개념 ERD 손그림](erd-sketch.jpg)`처럼 적고, Preview에서 그림이 보이는지 봅니다.

### Claude와 주고받기

- Claude에 워크시트를 넘길 때는 **편집 화면(Edit 탭)**의 글을 복사합니다. Preview나 파일 보기 화면에서 복사하면 표 기호가 빠집니다.
- 결과는 "마크다운 표로 줘"라고 받아 답 아래 Copy 단추로 복사하고, 빈 행 자리에 내용 행만 붙입니다(「[Claude 시작 가이드](claude-start-guide.md)」 4번).

### Day 4: `my-own-DESIGN.md` 올리기와 제출 링크

- 작업 폴더의 `my-own-DESIGN.md`를 **Add file → Upload files**로 저장소 맨 위에 올립니다.
- 제출할 워크시트 저장소 링크는 브라우저 주소창의 `https://github.com/아이디/axyourbody-worksheet`입니다. 로그아웃한 창(시크릿 창)에서 열면 404가 떠야 정상입니다. 비공개라는 뜻입니다.

## 지난 내용 되돌려 보기

`worksheet.md` 화면 오른쪽 위의 **History**(시계 아이콘)를 누르면 저장(Commit)한 순서대로 목록이 나옵니다. 하나를 누르면 그때 무엇을 고쳤는지 빨간 줄(지운 것)과 초록 줄(더한 것)로 보입니다. 지운 내용을 살리려면 그 화면에서 지워진 글을 복사해 지금 파일의 편집 화면에 다시 붙여 넣고 저장합니다. 그래서 한 워크시트를 끝낼 때마다 저장해 두면 언제든 돌아갈 수 있습니다.

## 자주 하는 실수와 고친 예

- **Public으로 만들었다** → Settings 맨 아래 **Danger Zone**의 **Change visibility**를 누르고 private을 고른 뒤, **I have read and understand these effects** → **Make this repository private**까지 누릅니다. 저장소 이름 옆 표시가 **Private**으로 바뀌었는지 봅니다.
- **저장소 이름을 잘못 썼다** (`axyourbody-worksheets`, `axyourbody worksheet` 등) → Settings 첫 화면(General)의 Repository name 칸에서 고치고 **Rename**을 누릅니다.
- **파일 이름을 `worksheet`나 `Worksheet.md`로 저장했다** → 파일을 열고 연필 아이콘을 눌러 위쪽 이름 칸을 `worksheet.md`로 고친 뒤 저장합니다.
- **표 행을 늘렸더니 Preview에서 표가 깨졌다** → 칸 안에 `|`를 썼거나 줄을 바꾼 곳이 있는지 찾아 쉼표로 고칩니다.
- **이미지가 안 보이고 글자만 나온다** → 올린 파일 이름과 `( )` 안의 이름이 대소문자, 확장자(`.jpg` · `.jpeg` · `.png`)까지 똑같은지 봅니다.

## 제대로 됐는지 확인

- [ ] **저장소가 비공개다** → 저장소 이름 옆에 **Private** 표시가 있습니다.
- [ ] **워크시트가 들어갔다** → 저장소 첫 화면에 `worksheet.md`가 있고, 열면 「AX YOUR BODY · 워크시트 문서」 제목과 차례가 보입니다.
- [ ] **강사를 초대했다** → Settings → Collaborators에 `wild-mental`이 Pending invite 또는 수락된 상태로 있습니다.
- [ ] **저장했다** → 저장소 첫 화면 위쪽에 방금 저장한 시간("now", "1 minute ago")이 보입니다.

## 막혔을 때

- **Copy raw file 아이콘이 안 보입니다.** 창이 좁으면 아이콘이 숨습니다. 창을 넓히거나, **Raw**를 눌러 열린 글 화면에서 `Cmd+A` → `Cmd+C`(Windows `Ctrl+A` → `Ctrl+C`)로 복사합니다.
- **creating a new file 링크가 없습니다.** 저장소에 이미 파일이 있으면 그 링크 대신 **Add file → Create new file**을 씁니다.
- **`wild-mental`이 검색되지 않거나 초대가 사라졌습니다.** 철자(가운데 하이픈)를 확인합니다. 초대는 7일 안에 수락되지 않으면 사라지므로, 목록에 없으면 다시 초대합니다.
- **Settings 탭이 없습니다.** 창이 좁으면 위쪽 탭 끝의 **⋯** 안에 있습니다. 그래도 없으면 내 계정의 저장소가 아니라 자료실 저장소를 보고 있는 것입니다. 주소에 내 아이디가 있는지 봅니다.
- 수업 전에 혼자 하다 막힌 단계는 표시해 두고 첫날 수업 시작 전에, 수업 중에는 손을 들어 현장에서 함께 해결합니다.

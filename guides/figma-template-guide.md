# Figma 템플릿 열기·복제 가이드

교재: 부록 A-3 Figma · 쓰는 날: Day 2~3 · 쓰는 곳: 내 Figma 파일 `axyourbody_이름_프로필ID`의 워크시트 페이지 세 개

## 이 가이드에서 볼 것

- Figma 템플릿 원본은 보기만 할 수 있습니다. **내 계정의 Drafts(초안)로 복제한 파일**에만 씁니다.
- 교재 부록 A-3의 일곱 단계를 실제 화면의 버튼 위치로 따라가고, 잠그기·카드 복사·강사에게만 공유하는 조작을 더합니다.
- 브라우저(figma.com)에서 하면 Mac과 Windows 화면이 같습니다. 단축키만 다릅니다(Mac `Cmd` · `Option` = Windows `Ctrl` · `Alt`).

템플릿 원본: [AX YOUR BODY Figma 템플릿](https://www.figma.com/design/m1TCwCzHWB0oVgRuekyCeT/AX-YOUR-BODY-Figma-Template) · 페이지별 칸과 완료 기준 체크리스트: [Figma 템플릿 안내](../figma-template/README.md)

## 1. 로그인하고 템플릿 열기

1. figma.com 오른쪽 위 **Log in**으로 로그인합니다. 계정이 없으면 **Sign up**으로 무료 계정을 만듭니다. 처음 가입하면 쓰임새를 묻는 질문이 몇 개 나오는데, 아무거나 골라도 되고 유료 플랜은 고르지 않습니다.
2. 위의 템플릿 원본 링크를 엽니다. 위쪽에 "View only"(보기 전용) 표시가 보이고 글자를 고칠 수 없으면 원본이 맞습니다.

## 2. 내 초안으로 복제하기

1. 캔버스의 빈 곳을 한 번 눌러 아무것도 고르지 않은 상태로 둡니다.
2. 왼쪽 위의 파일 이름(또는 그 옆 ▾)을 눌러 메뉴를 엽니다.
3. **Duplicate to your drafts**를 누릅니다. 화면에 따라 **Duplicate to drafts**로 보일 수 있습니다. 같은 기능입니다.
4. 복제가 끝나면 새 탭에 내 파일이 열립니다. 이름 앞뒤에 "Copy"가 붙어 있고, 글자를 고칠 수 있으면 내 파일입니다.

> [캡처 예정] 공통: 파일 이름 메뉴를 펼쳐 Duplicate to your drafts가 보이는 화면

**Drafts에 그대로 둡니다.** 무료 계정은 Drafts에서는 페이지 수 제한이 없지만, 팀 프로젝트로 옮기면 파일 하나에 페이지 3개까지만 쓸 수 있어 이 템플릿이 다 들어가지 않습니다. "Move to project" 같은 메뉴는 누르지 않습니다.

## 3. 파일 이름 바꾸기

1. 왼쪽 위의 파일 이름을 두 번 누르거나, 파일 이름 메뉴의 **Rename**을 누릅니다.
2. `axyourbody_이름_프로필ID`로 바꾸고 `Enter`를 누릅니다. 예) `axyourbody_홍길동_f-athlete`
3. 나중에 찾을 때는 figma.com 첫 화면 왼쪽의 **Drafts**에서 이 이름을 찾습니다.

## 4. 워크시트 페이지 찾기와 칸 이름 상자 잠그기

1. 왼쪽 패널 위쪽의 **Pages** 목록에서 세 페이지를 찾습니다: 「고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드」, 「과업별 화면 흐름 순서표와 화면 목록」, 「Google Stitch로 만든 테마별 화면 시안 비교표」. 페이지 목록이 접혀 있으면 Pages 글자 옆 화살표를 눌러 펼칩니다.
2. 칸 이름이 적힌 상자와 레인 이름 띠를 잠가 둡니다. 상자를 고르고 아래 단축키를 누르거나, 마우스 오른쪽 단추 메뉴의 **Lock/unlock**을 누릅니다. 왼쪽 레이어 목록에서 그 줄에 마우스를 올리면 나오는 자물쇠 아이콘을 눌러도 됩니다.

| 조작 | Mac | Windows |
|---|---|---|
| 잠그기·풀기 | `Shift+Cmd+L` | `Ctrl+Shift+L` |
| 복제 | `Cmd+D` | `Ctrl+D` |
| 끌어서 복사 | `Option`을 누른 채 끌기 | `Alt`를 누른 채 끌기 |
| 되돌리기 | `Cmd+Z` | `Ctrl+Z` |
| 화면 맞춤 보기 | `Shift+1` | `Shift+1` |

잠근 상자는 캔버스에서 눌러도 골라지지 않습니다. 고쳐야 할 때는 레이어 목록에서 자물쇠를 눌러 풉니다.

## 5. 「복사해서 쓰는 카드」로 카드 늘리기

1. 페이지 한쪽의 「복사해서 쓰는 카드」에서 쓸 카드를 누릅니다.
2. `Option`(Windows `Alt`)을 누른 채 끌어 레인 위에 놓으면 견본은 그대로 있고 복사본이 생깁니다.
3. 복사본의 글자를 두 번 눌러 고칩니다. 카드 모양과 종류 라벨은 레인에 맞는 견본을 골랐는지로 정해집니다(「[이벤트 보드 사용 가이드](event-board-guide.md)」).

## 6. 강사에게만 공유하고 링크 적기

1. 오른쪽 위의 **Share**를 누릅니다.
2. 초대 칸에 강사 이메일을 씁니다. 강사 이메일은 자료실 첫 화면의 [수업 연락처](../README.md#수업-연락처)에 있습니다.
3. 옆의 권한을 **can view**로 두고 **Send invite**(또는 **Invite**)를 누릅니다.
4. 같은 창의 링크 공개 범위(Who has access)를 **Only invited people**(초대한 사람만)로 둡니다. "Anyone"(링크가 있는 누구나)으로 되어 있으면 바꿉니다.
5. **Copy link**를 눌러 링크를 복사하고, 내 워크시트 저장소 `worksheet.md` 맨 위 「Figma 파일 링크 (강사만 열람):」 줄 뒤에 붙여 넣고 저장합니다(「[GitHub 워크시트 저장소 가이드](github-worksheet-repo-guide.md)」).

## 자주 하는 실수와 고친 예

- **원본에 쓰려고 했다** (글자가 안 고쳐지고 "View only"가 보임) → 2번대로 복제한 내 파일을 엽니다. 브라우저 탭 이름에 `axyourbody_`가 보여야 내 파일입니다.
- **복제를 여러 번 해서 파일이 여러 개다** → Drafts에서 쓰지 않는 사본에 마우스 오른쪽 단추 → **Delete**로 지우고 한 파일만 남깁니다.
- **FigJam 파일을 새로 만들어 썼다** → 이 수업의 템플릿은 Figma Design 파일입니다. FigJam(화이트보드 도구) 파일에 쓴 내용은 복사해 내 Design 파일의 해당 페이지로 옮깁니다.
- **칸 이름 상자를 지웠다** → 바로 `Cmd+Z`(Windows `Ctrl+Z`)로 되돌리고, 4번대로 잠급니다.
- **공유 링크를 "Anyone"으로 열어 두었다** → Share 창에서 Only invited people로 바꿉니다. 링크 주소는 그대로 써도 됩니다.

## 제대로 됐는지 확인

- [ ] **내 파일이다** → figma.com 첫 화면 **Drafts**에 `axyourbody_이름_프로필ID` 파일이 하나 있고, 열면 글자를 고칠 수 있습니다.
- [ ] **세 페이지가 있다** → Pages 목록에 워크시트 페이지 세 개가 모두 보입니다.
- [ ] **칸 이름 상자가 잠겼다** → 칸 이름 상자를 캔버스에서 눌러도 골라지지 않고, 레이어 목록에 자물쇠가 보입니다.
- [ ] **강사만 볼 수 있다** → Share 창의 사람 목록에 강사 이메일이 can view로 있고, Who has access가 Only invited people입니다.
- [ ] **링크를 적었다** → `worksheet.md` Preview에서 Figma 링크를 눌렀을 때 내 파일이 열립니다.

## 막혔을 때

- **Duplicate 메뉴가 보이지 않습니다.** 먼저 로그인했는지 봅니다. 로그아웃 상태에서는 복제할 수 없습니다. 레이어를 고른 상태에서는 메뉴가 달라지므로 캔버스 빈 곳을 누른 뒤 다시 파일 이름을 누릅니다.
- **템플릿 링크가 열리지 않습니다.** 자료실 저장소의 [figma-template 폴더](https://github.com/wild-mental/ax-wave-uxui-wildmental/tree/main/figma-template)에서 SVG 네 장(00-cover · 01-event-board · 02-screen-flow · 03-draft-comparison)을 내려받습니다(파일을 열고 **Download raw file**). figma.com 첫 화면에서 FigJam이 아닌 **Design** 파일을 새로 만들고, 왼쪽 Pages의 **+**로 페이지를 네 개 만든 뒤 페이지마다 SVG 한 장을 캔버스로 끌어다 놓습니다. 파일 이름은 3번대로 바꿉니다.
- **화면이 너무 커서 페이지 전체가 안 보입니다.** `Shift+1`로 화면에 맞춰 봅니다. 확대·축소는 `Cmd`(Windows `Ctrl`)를 누른 채 마우스 휠을 굴립니다.
- **Share 창에서 초대가 안 됩니다.** 이메일 주소에 띄어쓰기가 섞이지 않았는지 봅니다. 그래도 안 되면 수업 중에 손을 들어 현장에서 함께 해결합니다.

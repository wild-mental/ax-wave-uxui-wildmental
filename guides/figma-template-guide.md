## 목차 초안

1. Figma 무료 계정으로 로그인
2. 새 디자인 파일 만들고 이름 `axyourbody_이름_프로필ID`로 바꾸기
3. 자료실 `figma-template`에서 SVG 4개 내려받기
4. 페이지 네 개 만들고 교재의 워크시트 이름 붙이기
5. 페이지마다 SVG를 캔버스에 끌어다 놓기 (들어온 모습 정지 화면)
6. 글자 더블클릭해 고치기, 레이어 이름으로 찾기
7. 칸 이름 상자·레인 띠 잠그기 (Lock)
8. 「복사해서 쓰는 카드」 견본 복사해 늘리기 (Option/Alt 끌기)
9. 강사만 볼 수 있게 공유하기 (초대 또는 링크 범위 제한)
10. 공유 링크를 `worksheet.md` 맨 위 「Figma 파일 링크」에 붙이기
11. 막혔을 때
12. 화면 확인 날짜

### 이 가이드가 채울 것 (교재에 없는 것)

- 교재 A-3 다섯 단계를 화면으로
- SVG는 `_context/gen_figma_svgs.py`로 생성. 글자가 편집 가능한 텍스트로 들어오는지 Mac·Windows Figma에서 확인하고, 아니면 대처법(글상자 새로 얹기)을 적기
- 페이지 이름은 인쇄본 그대로: 「고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드」 「과업별 화면 흐름 순서표와 화면 목록」 「Google Stitch로 만든 테마별 화면 시안 비교표」
- 완성 모습 정지 화면 1장(빈 템플릿 상태)을 맨 위에

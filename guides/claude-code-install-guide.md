# Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)

교재: 부록 A-5 · Claude Code 데스크톱 앱 · 쓰는 때: 설치는 수업 전, 실습은 Day 3~4

## 이 가이드에서 볼 것

Claude Code는 따로 설치하는 프로그램이 아니라 **Claude 데스크톱 앱의 Code 탭**입니다. 명령어를 치는 터미널은 쓰지 않습니다. 이 가이드는 사전 안내의 4번과 8번을 화면 순서대로 풀고, 허락 요청을 읽는 법과 막혔을 때 할 일을 더합니다. 지시문을 보내고 프로토타입을 만드는 흐름은 「Claude Code 프로토타이핑 따라 하기」에서 다룹니다.

## 1. 내려받기와 설치

계정은 교육기관에서 받은 **Claude Pro 계정**을 씁니다. 브라우저에서 claude.ai에 먼저 로그인해 되는지 확인해 두면 앱 로그인이 빠릅니다.

| 단계 | Mac | Windows |
|---|---|---|
| 내 컴퓨터 확인 | 따로 고를 것이 없습니다. Mac용 파일 하나가 Intel·Apple 칩 모두에서 돌아갑니다 | **설정 → 시스템 → 정보**의 "시스템 종류"를 봅니다. "ARM 기반 프로세서"라고 나오면 ARM64용, 아니면 일반(x64)용을 받습니다 |
| 내려받기 | claude.ai/download에서 **Download for macOS**를 누릅니다. `.dmg` 파일이 받아집니다 | 같은 페이지에서 **Download for Windows**(x64) 또는 그 아래의 **ARM64** 설치 파일을 누릅니다 |
| 설치 | `.dmg`를 열고 Claude 아이콘을 **Applications**(응용 프로그램) 폴더로 끌어다 놓습니다 | 받은 설치 파일을 두 번 눌러 실행하고 안내대로 진행합니다 |
| 처음 실행 | 응용 프로그램 폴더에서 Claude를 엽니다. "인터넷에서 다운로드한 앱" 확인 창이 뜨면 **열기**를 누릅니다 | 시작 메뉴에서 Claude를 엽니다 |

## 2. 로그인하고 Code 탭 들어가기

1. 앱을 열고 교육기관에서 받은 Claude 계정으로 로그인합니다.
2. 앱 위쪽의 **Code** 탭을 누릅니다. 여기가 교재에서 말하는 "코드 작업(Claude Code) 화면"입니다.
3. 입력창 아래 줄에 왼쪽부터 **환경 선택**, **폴더 선택**, **모드 선택**, 오른쪽 끝에 **모델 선택**이 보이면 정상입니다.

> [캡처 예정] 공통: Code 탭 첫 화면과 입력창 아래 줄(환경 · 폴더 · 모드 · 모델)

환경 선택이 입력창 **위**에 있다면 예전 화면입니다. 아래 「막혔을 때」의 첫 항목대로 앱 버전을 올립니다.

## 3. 작업 폴더 만들기

바탕화면이나 문서 폴더에 빈 `axyourbody-prototype` 폴더를 만듭니다. **수업 전에는 이 빈 폴더 하나면 충분합니다**(사전 안내 8번과 같음). 그 안의 `context`, `design`, `data` 폴더는 Day 3에 교재 부록 A-5의 작업 폴더 그림대로 만듭니다.

| | Mac | Windows |
|---|---|---|
| 새 폴더 | Finder에서 바탕화면을 열고 **파일 → 새로운 폴더**(`Cmd+Shift+N`) | 파일 탐색기에서 바탕화면을 열고 빈 곳 오른쪽 클릭 → **새로 만들기 → 폴더**(`Ctrl+Shift+N`) |
| 이름 바꾸기 | 폴더를 고르고 `Return` | 폴더를 고르고 `F2` |
| 확장자 보이게 하기 (Day 4에 필요) | **Finder → 설정 → 고급 → 모든 파일 확장자 보기** 켜기 | 파일 탐색기 **보기 → 표시 → 파일 이름 확장명** 켜기 |

폴더 이름은 모두 **영문 소문자**로, 띄어쓰기 없이 씁니다.

## 4. 작업 폴더 열기

1. Code 탭 입력창 아래의 **환경 선택**에서 **Local**(내 컴퓨터)을 고릅니다.
2. 그 옆 **폴더 선택**을 누르고 `axyourbody-prototype` 폴더를 고릅니다. 하위 폴더(`context` 등)가 아니라 맨 위 폴더를 고릅니다.
3. 입력창에 "이 폴더에 무엇이 있는지 알려 줘"라고 쓰고 `Enter`를 누릅니다.
4. 폴더가 비어 있다는 답이 오면 정상입니다. Day 3에 `context`, `design`, `data` 폴더를 만든 뒤라면 세 폴더가 있다는 답이 옵니다.

Mac에서 "Claude이(가) '데스크탑' 폴더의 파일에 접근하려고 합니다" 같은 창이 뜨면 **허용**을 누릅니다. 작업 폴더를 열려면 필요합니다.

## 5. 허락 요청 읽는 법

입력창 아래 **모드 선택**에서 **Manual**을 고르면 Claude Code가 파일을 만들거나 고치기 전에 바뀌는 내용을 보여 주고 승인을 묻습니다. 처음에는 Manual로 두고, 익숙해지면 파일 편집을 자동으로 받아들이는 **Accept edits**로 바꿔도 됩니다. 앱 버전에 따라 이름이 "Ask permissions", "Auto accept edits"로 보일 수 있습니다.

**기본은 Manual이나 Accept edits입니다.** 교재와 이 가이드는 허락 요청을 읽고, 작업 폴더 밖의 수정을 거절하는 것을 전제로 합니다.

**Auto**(자동) 모드는 하나하나 묻지 않고 알아서 진행합니다. 아래 조건을 모두 갖췄을 때만 씁니다.

- Claude Code가 작업 폴더 밖의 파일을 건드리거나 시키지 않은 일을 하는 등 **의심스러운 작업을 보면 바로 직접 멈출 수 있다**(입력창의 정지 단추나 `Esc`). 그리고 그런 대응에 자신이 있다.
- 작업하는 컴퓨터에 **예민한 자료가 없다**. 개인 문서, 회사 자료, 비밀번호·인증서 파일, 실제 건강 기록 같은 것이 같은 컴퓨터에 있다면 Manual이나 Accept edits를 씁니다.
- 큰 변경 전에는 복사본(`-before-` 파일)을 꼭 만들어 두고, 끝난 뒤 바뀐 파일을 직접 열어 확인한다.

하나라도 자신이 없으면 Manual이나 Accept edits로 돌아갑니다. 모드 목록에 Auto가 없으면 Accept edits를 씁니다.

허락 요청이 뜨면 세 가지를 읽고 누릅니다.

- **어느 파일인가**: 경로가 `axyourbody-prototype` 안인지 봅니다.
- **무엇을 하는가**: 새로 만들기, 고치기, 지우기 중 무엇인지 봅니다. 지우기는 한 번 더 생각합니다.
- **지시한 일인가**: 내가 시킨 일과 관계없는 파일이면 거절합니다.

작업 폴더 밖의 파일을 고치겠다고 하면 거절하고 이렇게 보냅니다: "작업 폴더 밖은 고치지 마. 왜 그 파일이 필요한지 먼저 설명하고, 작업 폴더 안에서 할 수 있는 방법을 알려 줘."

## 6. 설치 확인 (수업 전에 여기까지)

- [ ] 앱에 교육기관 Claude 계정으로 로그인했다
- [ ] Code 탭 입력창 아래에 환경 · 폴더 · 모드 선택이 보인다
- [ ] 빈 `axyourbody-prototype` 폴더를 만들었다
- [ ] Local 환경에서 작업 폴더를 열고 "이 폴더에 무엇이 있는지 알려 줘"에 답을 받았다
- [ ] 파일 확장자가 보이게 설정했다

## 7. 사용 한도에 걸렸을 때: 다른 회사의 AI 코딩 도구

Claude Pro 계정에는 일정 시간 동안 쓸 수 있는 양이 있습니다. 남은 양은 입력창 아래 줄의 사용량 표시(동그라미)를 누르면 볼 수 있습니다. 한도를 다 써서 한동안 쓸 수 없으면, 아래 세 조건에 맞는 다른 회사의 AI 코딩 도구(예: OpenAI Codex, Cursor)로 이어서 작업해도 됩니다. 그 도구의 계정과 요금은 각 회사 안내를 따릅니다.

- 내 컴퓨터의 폴더를 작업 폴더로 열 수 있다
- 그 폴더 안의 파일을 읽고, 새로 만들고, 고칠 수 있다
- 대화로 지시하고 결과를 파일로 저장할 수 있다

| 그대로인 것 | 도구에 맞출 것 |
|---|---|
| 작업 폴더 `axyourbody-prototype`과 파일 이름 | 폴더 여는 메뉴 (예: Cursor는 **File → Open Folder**) |
| 지시문 킷의 지시문 내용 | 파일 가리키는 방법. `@context/service-structure.md`처럼 `@`를 쓰는 도구가 많지만, 안 되면 파일을 대화창에 끌어다 놓거나 "context 폴더의 service-structure.md 파일을 읽어"처럼 경로를 말로 씁니다 |
| 결과를 브라우저로 열어 확인하는 방법 | 허락을 묻는 방식과 버튼 이름 |

바꾼 뒤에도 "이 폴더에 무엇이 있는지 알려 줘"로 같은 폴더가 열렸는지 먼저 확인합니다. 한도가 다시 풀리면 Claude Code로 돌아와도 파일은 그대로 이어집니다.

## 막혔을 때

- **Code 탭이 안 보이거나 화면이 이 가이드와 다르다** → 앱 버전을 올립니다. Mac은 메뉴 막대 **Claude → Check for Updates…**, Windows는 **Help → Check for Updates…**를 누르고 앱을 다시 엽니다.
- **Code 탭에서 `Error 403` 같은 로그인 오류가 난다** → 앱 메뉴에서 로그아웃한 뒤 다시 로그인합니다. 그래도 안 되면 창만 닫지 말고 앱을 완전히 끈 뒤(Mac `Cmd+Q`, Windows 작업 관리자에서 Claude 끝내기) 다시 엽니다. 교육기관 계정이 아니라 개인 무료 계정으로 들어가 있지 않은지도 봅니다.
- **Windows에서 "Git is required"가 뜬다** → 먼저 앱 버전을 올립니다. 그래도 뜨면 Git for Windows(git-scm.com)를 설치하고 앱을 다시 엽니다.
- **"Failed to load session"이 뜬다** → 고른 폴더를 옮기거나 이름을 바꾸지 않았는지 봅니다. 폴더 선택에서 `axyourbody-prototype`을 다시 고릅니다.
- **앱이 하얀 화면에서 멈췄다** → 앱을 완전히 껐다가 다시 엽니다. 켤 때 업데이트가 자동으로 받아집니다.
- **Windows에서 "다른 설치가 진행 중" 오류가 난다** → 설치 파일을 오른쪽 클릭해 **관리자 권한으로 실행**합니다.

그래도 안 되면 막힌 화면을 캡처해 두고 첫날 수업 시작 전에 알려 주세요.

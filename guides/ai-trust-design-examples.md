# AI 판단 화면 신뢰 설계 예시 모음

교재: 3.7절 AI 판단 화면의 신뢰 설계 · 쓰는 곳: 테마별 첫 프로토타입의 AI 판단 카드 · 지시문: 「빈 상태·오류 등 상태 화면과 신뢰 요소 추가 지시문」의 신뢰 요소 부분 · 기록: 「테마별로 만든 첫 프로토타입과 버전 기록」의 관찰 메모

## 이 가이드에서 볼 것

교재 3.7의 「신뢰를 만드는 화면 요소 다섯 가지」 표에 무엇을 보여 주는지가 있습니다. 이 가이드는 그 다섯 요소와 함께 쓰는 두 가지 표현(신뢰도 표현 · 한 줄 → 펼치기)을 **좋은 예와 고칠 예**로 보여 줍니다.

예시는 모두 AX YOUR BODY 밖의 가상 서비스(도서관 앱, 가계부 앱, 배달앱, 반려견 기록 앱, 식물 물 주기 앱)에서 가져왔습니다. 내 프로필의 카드를 어떻게 채울지는 여러분이 내 데이터를 보고 정합니다. 예시를 옮겨 쓰지 말고, **고칠 예에 해당하는 곳이 내 화면에 있는지** 찾는 데 씁니다.

## 다섯 요소 한눈에

| 요소 | 한 줄 점검 질문 |
|---|---|
| 판단 | 카드 맨 위 한 문장만 읽고 무엇을 하면 되는지 아는가 |
| 근거 | 어떤 기록, 며칠치, 어떤 값을 봤는지 보이는가 |
| 한계 | 이 판단이 놓쳤을 수 있는 것이 이 카드에 한 줄로 있는가 |
| 전문가 확인 권장 | 필요할 때만, 색 없이도 눈에 띄게 나오는가 |
| 사용자의 선택 | 판단을 따르지 않는 길이 판단 바로 옆에 있는가 |

> [캡처 예정] 공통: 다섯 요소가 모두 들어간 가상 예시 카드 한 장 (요소마다 이름표)

## 판단: 결론 한 문장

좋은 예 (도서관 앱, 반납 알림 카드)

```text
이번 주 금요일까지 반납하면 연체되지 않아요.
```

고칠 예

```text
대출 패턴 분석 결과, 일부 도서에서 연체 가능성이 감지되었습니다.
```

**고칠 점.** 무엇을 하면 되는지 없고, "가능성이 감지"처럼 시스템의 말을 씁니다. 결론은 **사용자가 할 일이나 알아야 할 사실 하나**로 씁니다.

**주의.** 한 카드에 결론이 두 개면 카드를 나눕니다. 결론 문장은 카드에서 가장 큰 글자입니다.

## 근거: 기록의 종류 · 기간 · 값

좋은 예 (가계부 앱, 지출 카드)

```text
이번 달 외식비가 지난달 같은 기간보다 많아요.
근거  카드 내역 11/1~11/15 · 외식 12건 · 합계 18만 원 (지난달 같은 기간 9건 · 13만 원)
      [근거 자세히 ▾]
```

고칠 예

```text
이번 달 외식비가 많아요.
AI가 회원님의 소비 데이터를 종합적으로 분석했습니다.
```

**고칠 점.** "종합적으로 분석"은 근거가 아닙니다. **어떤 기록을, 언제부터 언제까지, 어떤 값으로** 봤는지 적습니다.

**주의.** 근거의 숫자는 화면 다른 곳의 숫자와 같아야 합니다. 내 프로토타입에서는 `data` 폴더 CSV에 있는 값만 근거가 됩니다. 근거 줄을 누르면 해당 기록 화면으로 이동하게 하면 더 좋습니다.

## 한계: 판단이 틀릴 수 있는 이유 한 줄

좋은 예 (배달앱, 도착 예상 카드)

```text
12시 40분쯤 도착할 것 같아요.
한계  비 오는 날의 배달 기록이 적어서 오늘은 예상보다 늦을 수 있어요.
```

고칠 예

```text
12시 40분쯤 도착할 것 같아요.
* AI의 예측은 부정확할 수 있으며 당사는 이에 대해 책임지지 않습니다.
```

**고칠 점.** 모든 카드에 붙는 면책 문구는 한계가 아닙니다. **이번 판단에 해당하는** 빠진 기록이나 다른 조건을 한 줄로 씁니다.

**주의.** 한계가 없으면 억지로 쓰지 않습니다. 빠진 기간, 측정 조건이 다른 기록, 사용자가 직접 입력해야만 아는 정보가 있을 때 씁니다.

## 전문가 확인 권장: 필요할 때만, 눈에 띄게

좋은 예 (반려견 기록 앱, 건강 기록 카드)

```text
[두꺼운 테두리 상자 · 카드 맨 위]
(i) 전문가 확인 권장
구토 기록이 이틀 연속이에요.
산책 계획보다 먼저 수의사와 상담해 주세요.
```

고칠 예

- 모든 카드 맨 아래에 작은 회색 글씨로 "건강 문제는 전문가와 상담하세요."
- 같은 경우를 빨간 배경으로만 표시하고 글자 라벨이 없음

**고칠 점.** 늘 붙어 있는 안내는 아무도 읽지 않습니다. **정해 둔 경우에만** 나오고, 나올 때는 카드 맨 위로 올라와 다른 판단보다 먼저 읽혀야 합니다.

**주의.** 라벨 글자("전문가 확인 권장"), 원형 i 아이콘, 두꺼운 테두리를 함께 씁니다. 어떤 경우에 나오는지는 내 서비스 구조 설명서와 상태 화면 목록을 보고 정합니다.

## 사용자의 선택: 따르지 않을 권리와 되돌리기

좋은 예 (식물 물 주기 앱, 오늘의 할 일 카드)

```text
오늘은 물을 주지 않아도 돼요.
근거  흙 습도 기록 어제 저녁 · 촉촉함
[다른 안 보기]   [원래 일정대로 물 주기]
```

"원래 일정대로 물 주기"를 누른 뒤에는 화면 아래에 "원래 일정으로 바꿨어요 · [되돌리기]"가 몇 초 동안 보입니다.

고칠 예

- 버튼이 "확인" 하나뿐이라 따르는 것 말고는 고를 수 없음
- 다른 선택이 설정 화면 깊은 곳에 있음
- 고른 뒤 되돌릴 방법이 없음

**고칠 점.** 선택 버튼은 **판단과 같은 카드 안**에 둡니다. 고른 결과는 바로 보여 주고 되돌릴 수 있게 합니다(사용성 원칙 "언제든 되돌리고 빠져나갈 수 있다").

**주의.** 선택 버튼은 주요 버튼보다 눈에 덜 띄어도 되지만, 찾기 어려우면 안 됩니다.

## 신뢰도 표현: 숫자보다 말로

판단을 얼마나 믿어도 되는지는 **판단에 쓴 기록의 양과 상태**로 말합니다.

좋은 예 (가계부 앱)

```text
기록이 6일치뿐이라 참고로만 봐 주세요. 2주 이상 쌓이면 더 정확해져요.
```

고칠 예

```text
신뢰도 92.7%
```

**고칠 점.** 사용자는 92.7%가 무엇의 비율인지, 그래서 어떻게 해야 하는지 알 수 없습니다. 근거가 없는 정확한 숫자는 오히려 믿음을 깎습니다.

**주의.** 신호등 색(초록·노랑·빨강)으로만 표현하지 않습니다. 쓴다면 "참고용", "충분함" 같은 글자를 함께 둡니다.

## 한 줄 → 펼치기 ("근거 자세히")

접힌 모습에는 판단과 근거 한 줄만 둡니다. "근거 자세히"를 누르면 같은 카드 안에서 근거 목록과 한계가 펼쳐집니다.

| 확인할 것 | 좋은 예 | 고칠 예 |
|---|---|---|
| 펼치는 단추 | "근거 자세히 ▾"처럼 글자와 화살표가 함께 있음 | 작은 아이콘 하나뿐 |
| 펼친 뒤 | 같은 카드 안에서 아래로 펼쳐지고, "접기 ▴"로 돌아옴 | 다른 화면으로 넘어가 돌아오기 어려움 |
| 접힌 상태 | 판단과 근거 한 줄은 늘 보임 | 근거가 모두 숨어 있어 펼치기 전에는 아무 근거도 없음 |
| 보여 주는 양 | 프로필에 맞게 기본 상태(접힘·펼침)를 정함 (교재 3.7) | 모든 사용자에게 처음부터 긴 설명 |

> [캡처 예정] 공통: 가상 예시 카드의 접힌 상태와 펼친 상태를 나란히

## 색 없이 구분하기

신뢰 요소는 아래 네 가지 중 **두 가지 이상**으로 구분합니다(교재 3.7).

- [ ] 글자 라벨: "근거", "한계", "전문가 확인 권장"이 글자로 적혀 있다
- [ ] 아이콘 모양: 전문가 확인 권장은 원형 i처럼 다른 요소와 모양이 다르다
- [ ] 테두리: 선 굵기나 선 모양(실선·점선)이 다르다
- [ ] 위치: 판단 바로 아래 같은 정해진 자리에 늘 같은 순서로 있다

확인은 화면을 흑백으로 바꿔서 합니다. 방법은 「Stitch 시안 만들기 가이드」 4단계의 흑백 보기를 봅니다. 흑백에서도 다섯 요소를 손가락으로 하나씩 짚을 수 있으면 통과입니다.

> [캡처 예정] Mac · Windows: 같은 가상 예시 카드를 색 그대로 / 회색 음영으로 본 모습

## 내 프로토타입에 적용할 때

1. 교재 3.7 [실습 안내]의 지시로 AI 판단 카드 하나를 바꿉니다. 바꾸기 전 복사본은 「Claude Code 프로토타이핑 따라 하기」 5단계 방법으로 만들어 둡니다.
2. 브라우저를 새로고침하고 위의 다섯 요소 점검 질문과 「색 없이 구분하기」를 확인합니다.
3. 고칠 예에 해당하는 곳이 있으면 한 가지씩 다시 지시합니다.

| 이렇게 나왔다 | 다시 지시하는 문장 |
|---|---|
| 근거가 "기록을 분석했어요"뿐이다 | {화면 이름}의 AI 판단 카드에서 근거를 "기록 종류 · 기간 · 값" 목록으로 바꿔 주세요. 값은 data 폴더 CSV에 있는 것만 씁니다. |
| 한계가 모든 카드에 같은 면책 문구다 | 한계 줄을 이 판단에 해당하는 빠진 기간이나 다른 측정 조건 한 줄로 바꿔 주세요. 해당하는 것이 없으면 한계 줄을 숨겨 주세요. |
| 전문가 확인 권장이 늘 보인다 | 전문가 확인 권장 상자는 {정해 둔 경우}일 때만 나오게 하고, 상태 미리 보기에서 그 경우를 켜 볼 수 있게 해 주세요. |
| 요소가 색으로만 구분된다 | 근거·한계·전문가 확인 권장에 글자 라벨을 붙이고, 전문가 확인 권장은 원형 i 아이콘과 두꺼운 테두리로도 구분되게 해 주세요. 색은 그대로 둡니다. |
| 선택 버튼이 없다 | 판단 아래에 "다른 안 보기" 버튼을 두고, 누르면 다른 안이 같은 카드 안에 보이게 해 주세요. 다른 화면은 바꾸지 마세요. |

4. 두 테마에 같은 지시를 적용한 뒤, 어느 테마에서 다섯 요소가 더 잘 읽히는지 버전 기록의 관찰 메모에 한 줄씩 적습니다.

## 막혔을 때

- 내 서비스에서 AI가 "판단"하는 화면이 어디인지 모르겠으면 화면 흐름 순서표의 화면 목록에서 AI가 결론을 말하거나 무엇을 권하는 화면을 찾습니다. 서비스 구조 설명서의 사건 중 AI가 하는 일도 단서입니다.
- 한계에 무엇을 쓸지 모르겠으면 내 상태 화면 목록의 빈 상태와 이상치 근거를 봅니다. 판단에 쓴 기간과 겹치는 것이 한계 후보입니다.
- 카드가 너무 길어졌으면 「한 줄 → 펼치기」로 접고, 접힌 상태에서 판단과 근거 한 줄만 남깁니다.
- Claude Code 조작은 「Claude Code 프로토타이핑 따라 하기」와 부록 A-5를 봅니다.

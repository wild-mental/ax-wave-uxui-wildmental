# 과업·불편 목록 가이드

교재: 1.4절 공통 PRD 읽는 법(머리칸), 1.5절 과업 찾기: JTBD로 쓰기(본표) · 쓰는 곳: 문서 템플릿 `worksheet.md`의 「타깃 사용자의 해야 할 일과 불편을 정리한 과업·불편 목록」

## 이 가이드에서 볼 것

과업·불편 목록은 두 번에 나눠 씁니다. 1부는 1.4절에서 담당 프로필을 고른 뒤 채우는 머리칸과, 1.5절에서 단서를 찾을 때 필요한 데이터셋 내려받기·열기입니다. 2부는 1.5절에서 채우는 본표입니다. 칸마다 무엇을 쓰는지는 교재 1.4절·1.5절의 [실습 안내] 표를, 작성 예시는 1.5절의 김도현 예제를 봅니다.

## 1부 · 머리칸과 데이터셋 (1.4절)

### 머리칸 쓰는 곳

`worksheet.md`를 열고 연필 아이콘을 눌러 편집합니다(부록 A-2). 「타깃 사용자의 해야 할 일과 불편을 정리한 과업·불편 목록」 제목 아래 "머리칸" 표(선택한 프로필 · 데이터 출처 · 고른 이유)에 씁니다. 선택한 프로필은 맨 위 기본 정보에서 체크한 프로필과 같게 씁니다. 데이터 출처 칸에는 해당하지 않는 말을 지우고 내 경우만 남깁니다. 고른 이유는 1.4절의 세 질문에 대한 답을 칸 안에서 줄을 바꾸지 않고 두세 문장으로 이어 씁니다. 다 쓰면 "Commit changes"로 저장합니다.

### 데이터셋 내려받기

1. 강사가 알려 준 온라인 자료실에서 데이터셋 항목을 엽니다.
2. 담당 프로필의 이름이 붙은 폴더(`m-general`, `f-general`, `m-athlete`, `f-athlete` 중 하나)를 내려받습니다.
3. 압축 파일(.zip)로 내려왔다면 풉니다. Mac은 파일을 더블클릭하고, Windows는 파일을 오른쪽 클릭한 뒤 "압축 풀기"(모두 압축 풀기)를 고릅니다.
4. 폴더 안에 `body.csv` · `meal.csv` · `sleep.csv` · `workout.csv` 네 파일이 있는지 확인합니다. 폴더와 파일 이름은 바꾸지 않습니다. Day 3에 이 네 파일을 작업 폴더 `axyourbody-prototype/data/`에 그대로 넣습니다(부록 A-5).

### 표 계산 프로그램으로 열기

- **Excel**: 파일 → 열기에서 CSV 파일을 고릅니다. 날짜 칸이 `#####`로 보이면 열 너비를 넓힙니다.
- **Google 스프레드시트**: 새 스프레드시트를 만들고 파일 → 가져오기 → 업로드로 CSV를 올립니다. 가져오기 위치를 "새 시트 삽입"으로 고르면 네 파일을 한 문서의 시트 네 장으로 모을 수 있습니다.
- **Numbers(Mac)**: CSV 파일을 더블클릭하거나 파일 → 열기로 엽니다.

읽기 전에 첫 줄(열 이름)을 고정해 두면 아래로 내려가도 열 이름이 보입니다. 메모나 색칠은 사본이나 Google 시트에서 하고, **원본 CSV 파일은 고쳐서 저장하지 않습니다.** 닫을 때 "CSV 형식으로 저장할까요?" 같은 질문이 나오면 저장하지 않습니다.

### 열 이름 읽는 법

열 이름은 영어 낱말을 밑줄 `_`로 이은 것입니다. 끝에 붙은 `_kg`, `_g`, `_pct`, `_hours`는 단위입니다.

| 파일 | 열 이름 → 뜻 |
|---|---|
| `body.csv` | `date` 날짜 · `weight_kg` 체중(kg) · `skeletal_muscle_kg` 골격근량(kg) · `body_fat_pct` 체지방률(%) · `measure_condition` 측정 조건 |
| `meal.csv` | `date` 날짜 · `meal` 끼니 · `carbs_g` 탄수화물(g) · `protein_g` 단백질(g) · `fat_g` 지방(g) |
| `sleep.csv` | `date` 날짜 · `sleep_hours` 수면 시간(시간) · `condition_1to5` 컨디션(1~5) |
| `workout.csv` (일반인) | `date` 날짜 · `type` 운동 종류 · `minutes` 운동 시간(분) · `activity` 한 운동 · `steps` 걸음 수 |
| `workout.csv` (운동인) | `date` 날짜 · `type` 운동 종류 · `minutes` 운동 시간(분) · `exercise` 종목 · `weight_kg` 무게(kg) · `reps` 반복 · `sets` 세트 · `rpe` RPE(운동 자각도, 10점 만점) |

- 한 줄이 기록 한 번입니다. `meal.csv`는 끼니마다, 운동인 `workout.csv`는 종목마다 한 줄이라 같은 날짜가 여러 줄일 수 있습니다.
- 기록하지 않은 날은 빈칸으로 남지 않고 **그 날짜의 줄이 아예 없습니다.** 날짜를 위에서 아래로 읽으며 건너뛰는 곳을 봅니다.
- `workout.csv`의 빈칸은 대개 그 운동에 해당하지 않는 항목입니다(무게가 없는 운동의 무게 칸 등).

무엇을 찾을지(빈칸·급변·리듬·거리)는 교재 1.5절의 "과업 단서는 어디에 있나"를 봅니다.

## 2부 · 본표 (1.5절)

### 템플릿에서 쓰는 곳

머리칸 아래 아홉 칸짜리 표가 본표입니다. 템플릿에는 과업 5까지 줄이 있습니다. 과업이 더 있으면 마지막 줄을 복사해 아래에 붙여 넣고 번호를 `과업 6`, `과업 7`로 바꿉니다. 거르고 남은 과업이 5개보다 적으면 빈 줄은 지웁니다. 한 줄은 `|`로 시작해 `|`로 끝나고 칸 수(9칸)가 머리줄과 같아야 표가 깨지지 않습니다. 칸 안에서는 `Enter`를 누르지 않고, 여러 항목은 ` · `로 나누고, 세로 막대 `|`는 쓰지 않습니다. 칸이 많아 헷갈리면 미리 보기(Preview) 탭으로 표를 확인한 뒤 저장합니다.

**근거 칸은 다시 찾아갈 수 있게** 씁니다. 출처 종류를 먼저 쓰고, 기록이면 파일 이름 · 날짜 · 열 · 값 순서로 씁니다.

- 프로필 카드: `카드 불편 ②`, `카드 하루 일과`
- 4주 기록: `sleep.csv {날짜} sleep_hours {값}` 처럼 실제로 열어 확인한 것만
- 인터뷰·내 경험: `짝 인터뷰`, `내 기록(수면 앱, 10월 둘째 주)`. 내 실제 기록은 수치 대신 "어느 기록, 언제"만 적어도 됩니다
- 아무 데도 없으면: `추측`

### 자주 하는 실수와 고친 예

- **기능을 과업으로 적었다** (배달앱 예: "배달 위치 알림 기능") → 상황과 하려는 일로 다시 씁니다: "점심시간 회의 직전에 주문했을 때, 음식이 언제 도착할지 알고 싶다. 그래서 회의 중에 전화를 받으러 나가지 않는다."
- **상황이 비었다** (도서관 앱 예: "책을 빌리고 싶다") → 언제·어디서·어떤 상태인지 넣습니다: "시험 기간 밤에 도서관이 닫힌 뒤, 내일 아침 빌릴 책이 남아 있는지 알고 싶다. 그래서 헛걸음하지 않는다."
- **빈도가 말로만 있다** ("자주", "가끔") → 횟수로 씁니다: "주 2회". 근거가 없으면 "짐작: 주 2회".
- **근거 칸에 Claude가 말한 날짜를 그대로 옮겼다** → CSV를 직접 열어 그 날짜와 값이 있는지 확인한 뒤 씁니다. 없으면 지우거나 "추측"으로 바꿉니다.
- **우선순위 "상"이 4개 이상이다** → 교재 1.5절 "Claude로 넓히고, 사람이 근거로 거른다"의 기준(빈도·불편의 크기·근거)으로 견줘 3개만 남기고 나머지는 "중"으로 내립니다. 지우지는 않습니다.

### 완료 기준 체크리스트 확인 방법

| 체크리스트 항목 | 이렇게 확인합니다 |
|---|---|
| 머리칸 세 칸(선택한 프로필·데이터 출처·고른 이유)을 채웠다 | 머리칸 표에 빈칸이 없고, 데이터 출처 칸에 해당하지 않는 말이 남아 있지 않습니다 |
| 과업을 5~7개 남겼다 (번호는 과업 1, 과업 2 …) | 본표의 줄 수를 셉니다. 번호가 빠짐없이 이어지는지 봅니다. Day 2부터 이 번호로 부릅니다 |
| 모든 과업에 근거를 적었다 (카드 항목, CSV 파일·날짜·값, 인터뷰. 없으면 "추측") | 근거 칸에 빈칸이 없는지 봅니다. 기록이 근거라면 파일 이름·날짜·값이 다 있고, 근거가 없는 과업은 "추측"이라고 적혀 있어야 합니다 |
| 빈도를 "매일", "주 2회"처럼 구체적으로 적고, 짐작이면 "짐작:"을 붙였다 | 빈도 칸에 "자주", "가끔" 같은 말이 없고 횟수가 보입니다. 카드·기록에서 확인하지 않은 빈도에는 "짐작:"이 붙어 있습니다 |
| 우선순위 "상"은 3개 이하다 | 우선순위 칸에서 "상"을 셉니다 |
| Claude가 제안한 과업은 근거 칸을 내가 직접 확인한 출처로 썼다 | Claude 후보에서 가져온 줄마다, 근거 칸에 적은 카드 항목이나 CSV 날짜를 내가 직접 열어 확인했는지 돌아봅니다. Claude의 답에 적힌 날짜를 그대로 옮긴 줄이 없어야 합니다 |

## 막혔을 때

- CSV가 한 칸에 몰려 보이면(쉼표가 그대로 보임) 프로그램의 가져오기 기능으로 다시 열고 구분 기호를 "쉼표"로 고릅니다.
- 단서가 안 보이면 교재 1.5절의 네 무늬 표를 옆에 두고 파일 하나씩, 무늬 하나씩 찾습니다. 한 번에 네 파일을 다 보지 않습니다.
- 후보를 넓힐 때는 교재 1.5절의 지시문을 씁니다(부록 A-1, 「Claude 시작 가이드」). 기능 이름이 섞여 나오면 이렇게 다시 묻습니다: "기능 이름이 들어간 후보만 골라 상황과 하려는 일로 다시 써 줘."
- 다 채웠으면 「페르소나 카드 가이드」로 넘어갑니다.

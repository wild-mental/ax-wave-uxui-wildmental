# 용어 대조표 작성 가이드

교재: 2.6절 용어 대조표: 시스템 내부 용어와 사용자 용어를 맞춘다 · 쓰는 곳: 문서 템플릿 `worksheet.md`의 「시스템 내부 용어와 사용자 용어를 맞춘 용어 대조표」

## 이 가이드에서 볼 것

용어 대조표는 대상 카드의 시스템 내부 용어 옆에 화면에 나갈 이름을 붙이는 약속표입니다. 이 가이드는 `worksheet.md`의 표를 채우는 순서와 칸 안에 쓰는 요령, 이름을 정할 때 자주 하는 실수를 다룹니다. 칸마다 무엇을 쓰는지는 교재 2.6의 [실습 안내] 표를, 두 프로필을 나란히 본 예는 같은 절의 예제를 봅니다.

## 템플릿에서 쓰는 곳

`worksheet.md`를 편집 모드로 열고(부록 A-2) 「시스템 내부 용어와 사용자 용어를 맞춘 용어 대조표」 제목 아래 표를 찾습니다.

**채우는 순서.**

1. 대상 카드 표의 대상 열을 위에서부터 그대로 옮겨 시스템 내부 용어 칸에 적습니다. 대상 하나가 한 줄입니다. 빈 줄이 모자라면 빈 줄 한 줄을 통째로 복사해 바로 아래에 붙이고, 다 쓴 뒤 남은 빈 줄은 지웁니다.
2. 화면에 자주 나올 속성(예: 대상 카드에서 값으로 표시한 것)이나 버튼에 쓸 동사 표현이 있으면 그 아래에 행을 더합니다.
3. 사용자 용어 → 쓰는 맥락 · 뜻 차이 → 피할 말 → 근거 순서로 채웁니다.
4. 리뷰 메모 칸은 비워 두었다가 2.9절 동료 리뷰 때 채웁니다.

**칸 안에 쓰는 요령.**

- 한 대상이 화면마다 다른 이름으로 나가면 사용자 용어 칸에 모두 적고, 이름 뒤 괄호에 화면을 붙입니다. 여러 이름은 교재 [실습 안내] 표의 예처럼 ` / `로 나눕니다. 칸 안에서는 줄을 바꾸지 않고 `|` 기호도 쓰지 않습니다.
- 피할 말이 여럿이면 ` · `로 나눕니다.
- 근거 칸에는 페르소나 카드의 어느 칸에서 왔는지 짧게 적습니다. 예) `페르소나 카드 · 이 사람이라면 이렇게 말할 것`
- 저장 전에 미리 보기(Preview)에서 표가 깨지지 않았는지 확인합니다.

## 자주 하는 실수와 고친 예

- **같은 대상을 화면마다 다르게 불렀다** (도서관 앱 예: "대출 기록 / 대출 내역 / 대출 히스토리") → 한 맥락에 한 이름만 남깁니다: 사용자 용어 "빌린 책", 피할 말 "대출 내역 · 대출 히스토리".
- **내부 용어를 화면 이름으로 적었다** ("loan_status", "세션 ID") → 사용자가 소리 내 읽을 수 있는 말로 바꿉니다: "반납 상태".
- **버튼 이름을 명사로만 적었다** ("반납") → 동사와 명사를 함께 씁니다: "책 반납하기".
- **숫자에 단위가 없다** ("3") → "3일 남음"처럼 단위를 붙입니다.
- **뜻이 갈리는 말을 그냥 두었다** (도서관 앱 예: "예약"이 좌석 예약과 책 예약에 함께 쓰임) → 이름을 나눕니다: "좌석 예약", "책 예약 대기". 쓰는 맥락 · 뜻 차이 칸에 어디서 헷갈리는지 적습니다.

## 완료 기준 체크리스트 확인 방법

- [ ] **대상 카드의 모든 대상에 사용자 용어를 붙였다** → 대상 카드 표의 행 수와 용어 대조표에서 대상을 옮긴 행 수가 같은지 세고, 사용자 용어 칸이 빈 줄이 없는지 봅니다. 화면에 쓰지 않는 대상이면 비워 두지 말고 "(화면에 쓰지 않음)"이라고 적습니다.
- [ ] **맥락에 따라 뜻이 달라지는 말을 표시했다** → 사용자 용어가 둘 이상인 행, 그리고 사용자의 일상 말과 서비스의 뜻이 다른 단어의 행에서 쓰는 맥락 · 뜻 차이 칸이 채워져 있는지 봅니다.
- [ ] **피할 말을 적었다** → 피할 말 칸이 모두 비어 있지 않은지 봅니다. 대상 카드를 쓰는 동안 섞어 쓴 이름이 있었다면 그 이름이 여기 들어가야 합니다.
- [ ] **짝의 리뷰를 받아 리뷰 메모를 채웠다** → 2.9절을 마친 뒤 확인합니다. 짝이 다르게 짐작한 이름마다 리뷰 메모에 결정(유지/변경)이 있는지 봅니다.

## 막혔을 때

- 이름이 떠오르지 않으면 페르소나 카드의 "이 사람이라면 이렇게 말할 것"을 소리 내 읽어 보고, 그 말투에 나오는 낱말부터 후보로 적습니다.
- Claude에게 물을 때는 이름을 대신 짓게 하기보다 점검을 받습니다: "아래 용어 대조표에서 같은 대상을 다르게 부른 곳과 사용자가 낯설어할 말을 골라 줘. 새 이름은 제안하지 말고 이유만 적어 줘." (부록 A-1)
- 맥락마다 뜻이 달라지는 단어를 찾는 감은 교재 2.6의 "기록" 단어 설명과 2.3의 ⑤ 이름 Label을 다시 봅니다.
- 앞 단계는 「대상 카드 작성 가이드」, 다음 단계는 「진입점 선택표 작성 가이드」이고, 리뷰 메모는 「동료 리뷰 진행 가이드」를 따릅니다.

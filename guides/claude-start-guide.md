# Claude 시작 가이드

교재: 부록 A-1 Claude (웹·데스크톱 앱) · 쓰는 날: Day 1~4 · 쓰는 곳: 교재 [실습 안내]의 지시문 → 워크시트 문서 `worksheet.md`

## 이 가이드에서 볼 것

- Claude는 웹(claude.ai)과 데스크톱 앱 어느 쪽에서 써도 같은 계정이면 대화 목록이 같이 보입니다. 이 수업에서는 **교육기관에서 받은 Claude Pro 계정**으로 로그인합니다.
- 교재 부록 A-1의 네 단계(로그인 → 지시문 붙여 넣기 → 확인 후 워크시트로 옮기기 → 대화 나누기)를 실제 화면의 버튼 이름으로 따라갑니다.
- 파일 첨부, 결과를 표로 받아 `worksheet.md`에 옮기는 요령, 대화에 넣지 말아야 할 것을 함께 봅니다.

Day 3~4에 쓰는 데스크톱 앱의 **Code** 탭(Claude Code)은 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](claude-code-install-guide.md)」에서 다룹니다. 이 가이드는 대화(Chat) 화면만 다룹니다.

## 1. 로그인하기

### 웹 (Mac · Windows 공통)

1. 브라우저 주소창에 `claude.ai`를 입력합니다.
2. 교육기관 안내에 적힌 방법으로 로그인합니다. 이메일 계정이면 이메일 주소를 쓰고 **Continue with email**을 누른 뒤, 그 메일함으로 온 로그인 메일의 링크를 누릅니다. Google 계정이면 **Continue with Google**을 누릅니다.
3. 왼쪽에 대화 목록이, 가운데에 입력창이 보이면 로그인된 것입니다.

### 데스크톱 앱

| 단계 | Mac | Windows |
|---|---|---|
| 앱 열기 | **응용 프로그램**(Applications) 폴더나 Launchpad에서 Claude를 엽니다 | **시작** 메뉴에서 Claude를 찾아 엽니다 |
| 로그인 | 웹과 같은 계정, 같은 방법으로 로그인합니다 | 웹과 같은 계정, 같은 방법으로 로그인합니다 |
| 확인 | 위쪽에서 **Chat** 화면을 고르고, 웹에서 만든 대화가 왼쪽 목록에 보이는지 봅니다 | 위쪽에서 **Chat** 화면을 고르고, 웹에서 만든 대화가 왼쪽 목록에 보이는지 봅니다 |

> [캡처 예정] Mac · Windows: 데스크톱 앱 로그인 직후 화면 (Chat · Code 전환 위치 표시)

앱 설치가 아직이면 사전 안내 4번과 「[Claude Code 데스크톱 앱 설치 (Mac판 · Windows판)](claude-code-install-guide.md)」를 먼저 봅니다.

## 2. 새 대화를 열고 지시문 넣기

1. 왼쪽 위의 **New chat**(새 채팅)을 누릅니다. 실습 하나마다 새 대화를 엽니다.
2. 교재 [실습 안내]의 지시문을 입력창에 씁니다. Part 1~2의 지시문은 [Part 1·2 지시문 킷](../kits/claude-prompts-part-1-2.md)에서 복사하고, 지시문에 붙여 넣을 공통 PRD와 프로필 카드의 글은 자료실의 [공통 PRD · 프로필 카드](../textbook-materials/)에서 복사합니다. Part 3~4의 지시문은 [지시문 킷](../kits/claude-code-prompts.md)에서 복사합니다.
3. `{ }` 부분을 모두 내 내용으로 바꿉니다. 중괄호 기호 `{` `}`도 지웁니다.
4. 줄을 바꿀 때는 `Shift+Enter`를 누릅니다. `Enter`만 누르면 바로 보내집니다.
5. 보내기 전에 지시문을 한 번 훑어 남은 `{`가 없는지 봅니다.

## 3. CSV·이미지 파일 첨부하기

1. 입력창 왼쪽 아래의 **+** 단추를 누르고 **Add files or photos**를 고릅니다. 파일 창에서 파일을 골라 엽니다.
2. 파일을 입력창 위로 끌어다 놓아도 첨부됩니다. 화면 캡처 이미지는 복사한 뒤 입력창에 붙여 넣어도 됩니다.
3. 입력창 위에 파일 이름이 카드처럼 보이면 첨부된 것입니다. 지시문을 함께 쓰고 보냅니다.

> [캡처 예정] 공통: + 단추를 눌러 Add files or photos가 보이는 화면, CSV 네 개가 첨부된 입력창

CSV는 고른 프로필 폴더의 네 파일을 그대로 첨부합니다. 첨부해도 내 컴퓨터의 원본 파일은 바뀌지 않습니다. **내 실제 기록**으로 실습한다면, 사본을 만들어 넣고 싶지 않은 열과 날짜를 지운 뒤 그 사본만 첨부합니다. 어디까지 넣을지는 여러분이 정합니다(교재 부록 A-1 주의할 점).

## 4. 결과를 워크시트로 옮기기

1. 지시문 끝에 "마크다운 표로 줘"를 붙이거나, 답을 받은 뒤 "방금 결과를 워크시트 표와 같은 열 순서의 마크다운 표로 다시 줘"라고 합니다.
2. 옮기기 전에 근거부터 확인합니다. 날짜나 값이 나오면 "그 판단의 근거가 된 줄을 파일 이름 · 날짜 · 값으로만 보여 줘"라고 묻고, CSV를 직접 열어 그 줄이 있는지 봅니다. 없으면 옮기지 않습니다.
3. 답 아래에 마우스를 올리면 나오는 **Copy**(복사) 단추를 누릅니다. 마우스로 표를 끌어 고르는 것보다 마크다운 기호가 그대로 복사됩니다.
4. `worksheet.md`의 편집 화면에서 빈 행 자리에 붙여 넣습니다. 맨 위 제목 줄과 `|---|` 줄은 워크시트에 있던 것을 그대로 두고, Claude가 준 표에서는 내용 행만 가져옵니다. 저장과 Preview 확인은 「[GitHub 워크시트 저장소 가이드](github-worksheet-repo-guide.md)」를 봅니다.

> [캡처 예정] 공통: 답 아래 Copy 단추 위치

## 5. 대화가 길어질 때 나누기

같은 주제로 오래 주고받으면 앞부분 내용을 놓치거나 답이 느려집니다. 지시문 서너 번을 넘게 고쳐 묻고 있다면 나눌 때입니다.

1. 지금 대화에 이렇게 보냅니다: "지금까지 정한 결론만 다섯 줄로 요약해 줘. 새 대화에 붙여 넣을 거야. 아직 정하지 못한 것은 따로 한 줄로 적어 줘."
2. 요약을 Copy로 복사합니다.
3. **New chat**으로 새 대화를 열고, 요약을 먼저 붙여 넣은 뒤 다음 지시를 이어 씁니다. 필요한 CSV는 새 대화에 다시 첨부합니다.

## 6. 넣지 말아야 할 것

- 회사·가족·친구 등 **다른 사람의 개인정보**(이름, 연락처, 건강 정보, 대화 캡처)는 넣지 않습니다.
- 내 실제 신체 수치·검진 수치·증상은 넣을 범위를 스스로 정합니다. 망설여지면 가상 프로필 데이터셋을 씁니다.
- 첨부할 화면 캡처에 알림, 다른 사람의 이름, 메신저 대화가 보이면 잘라 내고 올립니다.

## 자주 하는 실수와 고친 예

- **`{ }`를 그대로 두고 보냈다** (도서관 앱 예: "{책 제목}의 반납일을 알려 줘") → 답이 엉뚱하면 같은 대화에 "앞 지시문의 {책 제목}은 '데미안'이야. 다시 해 줘."라고 보냅니다.
- **교재 예제 프로필 이름을 그대로 두었다** → 내 프로필 이름과 데이터셋 폴더 이름(`m-general` 등)으로 바꿨는지 보내기 전에 확인합니다.
- **표를 마우스로 끌어 복사해 붙였더니 칸이 깨졌다** → 답 아래 Copy 단추로 다시 복사합니다.
- **CSV를 첨부하지 않고 "내 데이터를 분석해 줘"라고 했다** → 입력창 위에 파일 카드가 보이는지 확인하고 다시 보냅니다.
- **한 대화에서 Day 1부터 Day 2까지 이어 썼다** → 5번 방법으로 결론만 요약해 새 대화로 옮깁니다.

## 제대로 됐는지 확인

- [ ] **웹과 앱에 로그인했다** → 웹에서 보낸 대화가 데스크톱 앱 왼쪽 목록에도 보입니다.
- [ ] **지시문을 내 내용으로 바꿨다** → 보낸 지시문을 다시 읽어 `{`와 교재 예제 이름이 남지 않았습니다.
- [ ] **파일이 첨부됐다** → 내 메시지 위에 파일 이름 카드가 붙어 있습니다.
- [ ] **결과를 워크시트로 옮겼다** → `worksheet.md`의 Preview에서 표가 칸에 맞게 보이고, 옮긴 날짜·값을 CSV에서 직접 찾았습니다.

## 막혔을 때

- **로그인 메일이 오지 않습니다.** 스팸함을 보고, 1~2분 뒤 다시 요청합니다. 계정 정보가 맞는지는 교육기관 안내를 다시 봅니다. 그래도 안 되면 첫날 수업 시작 전에 현장에서 함께 해결합니다.
- **"사용 한도에 가까워졌다"는 안내가 뜹니다.** 일정 시간이 지나면 다시 쓸 수 있습니다. 긴 대화를 새 대화로 나누면 한도를 덜 씁니다. Day 3~4의 작업 폴더 실습 중에 한도를 다 썼다면 사전 안내 5번의 조건에 맞는 다른 회사의 AI 코딩 도구(OpenAI Codex, Cursor 등)를 써도 됩니다([사전 안내](../pre-course-notice.md)).
- **파일이 첨부되지 않습니다.** 파일 이름에 특수문자가 많으면 영문으로 바꿔 다시 첨부합니다. 엑셀(`.xlsx`)로 저장한 사본이면 CSV로 다시 저장해 첨부합니다.
- **답이 지시와 다릅니다.** 원하는 결과를 한 문장으로 다시 쓰고, "먼저 무엇을 바꿀지 목록으로 보여 줘"라고 덧붙입니다.
- 수업 중에 막히면 손을 들어 현장에서 도움을 받습니다.

## 목차 초안

1. 웹에서 로그인하기 / 데스크톱 앱에서 로그인하기 (Mac · Windows)
2. 새 대화를 열고 교재 지시문 붙여 넣기 (`{ }` 바꾸기)
3. CSV·이미지 파일 첨부하기
4. 결과를 워크시트로 옮기기 ("마크다운 표로 줘")
5. 대화가 길어질 때 새 대화로 나누고 결론만 요약해 넘기기
6. 넣지 말아야 할 정보 (실제 수치 범위는 스스로, 타인 정보 금지)
7. 막혔을 때 (FAQ)
8. 화면 확인 날짜

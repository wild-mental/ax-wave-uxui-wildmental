## 목차 초안

1. 준비: 배포 전 점검표 끝내기, `deploy` 폴더에 두 파일만
2. 배포 전용 공개 저장소 만들기 (New repository → Public)
3. 두 파일 올리기 (Upload files, 폴더째 올리지 않기)
4. Pages 켜기 (Settings → Pages → Deploy from a branch → main · / (root) → Save)
5. 공개 주소 확인과 Actions 탭 초록 체크
6. 휴대폰·시크릿 창으로 확인, 주소 기록
7. 고쳐서 다시 올리기와 강력 새로 고침
8. 404일 때
9. 잘못 올렸을 때: 저장소 지우고 새로 만들기
10. 워크시트 저장소(비공개)와 헷갈리지 않기
11. 화면 확인 날짜

# Figma 템플릿 — SVG를 끌어다 놓아 내 Figma 파일 만들기

Figma에서 쓰는 워크시트 세 개(이벤트 보드 · 화면 흐름 순서표와 화면 목록 · 시안 비교표)를 SVG 파일로 준비했습니다. 내 Figma 파일에 끌어다 놓으면 칸 이름 상자·레인·표·체크리스트가 고칠 수 있는 도형과 글자로 들어옵니다. 교재 부록 A-3과 「[Figma 템플릿 만들기 가이드](../guides/figma-template-guide.md)」를 함께 봅니다.

## 내려받을 파일

| 페이지 | 파일 |
|---|---|
| 00 표지 | [00-cover.svg](00-cover.svg) |
| 01 고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드 | [01-event-board.svg](01-event-board.svg) |
| 02 과업별 화면 흐름 순서표와 화면 목록 | [02-screen-flow.svg](02-screen-flow.svg) |
| 03 Google Stitch로 만든 테마별 화면 시안 비교표 | [03-draft-comparison.svg](03-draft-comparison.svg) |

링크를 열고 오른쪽 버튼 → 「다른 이름으로 링크 저장」으로 내려받습니다.

## 만드는 순서

1. Figma에서 새 디자인 파일을 만들고 이름을 `axyourbody_이름_프로필ID`로 바꿉니다. 예) `axyourbody_홍길동_f-athlete`
2. 왼쪽 페이지 목록에서 페이지를 네 개 만들고 위 표의 페이지 이름을 그대로 붙입니다.
3. 페이지마다 해당 SVG 파일을 캔버스에 끌어다 놓습니다.
4. 들어온 상자 안의 글자를 더블클릭해 고칩니다. 레이어 목록에는 "여정 레인", "단계 1", "사건 카드 견본"처럼 이름이 붙어 있습니다.
5. 칸 이름 상자와 레인 이름 띠는 잠가 두면(Lock) 실수로 지우지 않습니다.
6. 카드는 오른쪽 「복사해서 쓰는 카드」의 견본을 복사해(Mac Option, Windows Alt를 누른 채 끌기) 레인에 붙입니다.

색만으로 구분하지 않습니다. 카드는 **라벨 글자와 모양**으로 구분되어 흑백으로 출력해도 읽힙니다.

아래는 각 페이지에 들어 있는 칸과 완료 기준 체크리스트입니다. SVG 안의 내용과 같습니다.

## 01 · 고객 여정 위에 사건과 대상 객체를 붙인 이벤트 보드 (2.2절, 2.4)

가로로 긴 프레임에 위에서부터 레인(가로 줄) 네 개를 둡니다. 레인 왼쪽 끝에 레인 이름 상자를 둡니다.

| 레인 | 쓰는 것 | 카드 모양 |
|---|---|---|
| 1. 여정 | 단계 · 근거 날짜 · 행동 · 생각 · 감정(-2~+2 숫자와 낱말, 단계 사이를 실선으로 잇기) · 접점 · 불편 · 기회 | 단계별 큰 상자 (단계 4~6개) |
| 2. 사건 | 시간순 과거형 사건 (예: "세트가 기록됨") | 가로로 긴 직사각형 |
| 3. 대상 객체 | 사건 속 명사 (예: "세트", "운동 세션") | 정사각형 |
| 4. 질문 | 지금 답할 수 없는 것 | 모서리에 "?" 표시 |

- 카드마다 종류 라벨(**사건 / 대상 객체 / 질문**)을 글자로 적습니다.
- 여정 레인의 단계 상자 안에는 위 일곱 칸의 이름을 작은 글자로 미리 적어 둡니다.

완료 기준 체크리스트
- [ ] 여정 단계를 4~6개 적고 단계마다 근거 날짜를 붙였다
- [ ] 사건을 과거형으로 10개 이상 시간순으로 붙였다
- [ ] 사건마다 등장하는 대상 객체를 대상 객체 레인에 붙였다
- [ ] 대상 객체 레인의 대상 객체를 문서 템플릿의 대상 객체 카드로 옮겼다 (대상 객체 행으로, 또는 다른 대상 객체의 속성으로)

## 02 · 과업별 화면 흐름 순서표와 화면 목록 (3.2절)

위에서 아래로 영역 다섯 개를 둡니다. 기본 흐름과 갈림길은 나중에 그대로 복사해 `context/screen-flow.md`에 붙일 수 있도록 **글자로** 씁니다.

| 영역 | 쓰는 것 |
|---|---|
| 핵심 과업 | 과업·불편 목록에서 고른 과업 한 문장 |
| 기본 흐름 | 화면 이름을 화살표로 이은 한 줄. 그림·배치 없이 이름만 |
| 갈림길 | [조건]과 다른 경로 한 줄 (없으면 비움) |
| 화면 목록 | 화면 이름 · 이 화면의 목적 · 측정 지표 1개 (표처럼 가로 한 줄에 상자 세 개) |
| 상태 화면 목록 | 상태 · 어느 화면 · 근거 데이터 · 보여 줄 것 (가로 한 줄에 상자 네 개) |

완료 기준 체크리스트
- [ ] 핵심 과업 1개의 기본 흐름을 처음부터 끝까지 화면 이름으로 이었다
- [ ] 갈림길이 있으면 조건과 함께 적었다
- [ ] 화면마다 목적과 측정 지표 1개를 적었다
- [ ] 상태 화면 4종(빈·오류·로딩·이상치)을 적고, 빈 상태와 이상치에는 근거 데이터를 붙였다
- [ ] 내용을 작업 폴더 `context/screen-flow.md`로 옮겼다

## 03 · Google Stitch로 만든 테마별 화면 시안 비교표 (3.5절)

테마마다 가로 한 줄을 쓰고, 열 6개를 둡니다.

| 열 | 쓰는 것 |
|---|---|
| 테마 | DESIGN.md 후보 쇼핑 목록의 테마 이름 |
| 시안 화면 | 화면 이름 2~3개와 Stitch에서 내보낸 시안 이미지 |
| 과업 수행 쉬움 | ○ / △ / × + 이유 한 줄 |
| 정보 위계 | ○ / △ / × + 이유 한 줄 |
| 프로필 적합성 | ○ / △ / × + 이유 한 줄 |
| 한 줄 결론 | 어느 테마의 어느 부분이 좋았는지, 첫 프로토타입을 어떤 테마로 만들지 |

완료 기준 체크리스트
- [ ] 테마 2개 이상 × 핵심 화면 2개 이상의 시안을 붙였다
- [ ] 세 기준을 모두 ○/△/×와 이유로 평가했다
- [ ] 테마마다 한 줄 결론을 적었다

## 공유

제출할 때 Figma 공유 설정에서 강사만 볼 수 있게 초대하거나 링크 공유 범위를 제한하고, 공유 링크를 내 워크시트 저장소의 `worksheet.md` 맨 위 Figma 링크 칸에 적습니다(교재 부록 A-3).

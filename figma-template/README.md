# Figma 템플릿 — 내 Figma 파일 만들기

Figma에서 쓰는 워크시트 세 개(이벤트 보드 · 화면 흐름 순서표와 화면 목록 · 시안 비교표)를 내 Figma 파일 하나에 직접 만듭니다. 이 안내대로 만들면 교재의 [실습 안내]와 같은 칸 이름·순서가 됩니다. 조작 방법은 교재 부록 A-3과 「[Figma 템플릿 만들기 가이드](../guides/figma-template-guide.md)」를 봅니다.

## 파일 공통

- 새 디자인 파일을 만들고 이름을 `axyourbody_이름_프로필ID`로 바꿉니다. 예) `axyourbody_홍길동_f-athlete`
- 페이지는 네 개입니다: `00 표지` · `01 고객 여정 위에 사건과 대상을 붙인 이벤트 보드` · `02 과업별 화면 흐름 순서표와 화면 목록` · `03 Google Stitch로 만든 테마별 화면 시안 비교표` (교재에 나오는 워크시트 이름 그대로)
- `00 표지`에는 이름 · 담당 프로필 · 워크시트 저장소 링크를 적는 글상자를 둡니다.
- 워크시트 페이지마다 큰 프레임 하나를 만들고, **왼쪽 위에 워크시트 이름**, **오른쪽 위에 완료 기준 체크리스트 상자**를 둡니다. 체크리스트는 아래 각 절의 목록을 그대로 옮겨 적고, 끝낸 항목 앞에 ✓를 씁니다.
- 색만으로 구분하지 않습니다. 카드와 상자는 **라벨 글자와 모양**으로도 구분되게 만듭니다. 흑백으로 출력해도 읽혀야 합니다.
- 칸 이름이 적힌 상자는 만든 뒤 잠가 두면(Lock) 실수로 지우지 않습니다.

## 01 · 고객 여정 위에 사건과 대상을 붙인 이벤트 보드 (2.2절, 2.4)

가로로 긴 프레임에 위에서부터 레인(가로 줄) 네 개를 둡니다. 레인 왼쪽 끝에 레인 이름 상자를 둡니다.

| 레인 | 쓰는 것 | 카드 모양 |
|---|---|---|
| 1. 여정 | 단계 · 근거 날짜 · 행동 · 생각 · 감정(-2~+2 숫자와 낱말, 단계 사이를 실선으로 잇기) · 접점 · 불편 · 기회 | 단계별 큰 상자 (단계 4~6개) |
| 2. 사건 | 시간순 과거형 사건 (예: "세트가 기록됨") | 가로로 긴 직사각형 |
| 3. 대상 | 사건 속 명사 (예: "세트", "운동 세션") | 정사각형 |
| 4. 질문 | 지금 답할 수 없는 것 | 모서리에 "?" 표시 |

- 카드마다 종류 라벨(**사건 / 대상 / 질문**)을 글자로 적습니다.
- 여정 레인의 단계 상자 안에는 위 일곱 칸의 이름을 작은 글자로 미리 적어 둡니다.

완료 기준 체크리스트
- [ ] 여정 단계를 4~6개 적고 단계마다 근거 날짜를 붙였다
- [ ] 사건을 과거형으로 10개 이상 시간순으로 붙였다
- [ ] 사건마다 등장하는 대상을 대상 레인에 붙였다
- [ ] 대상 레인의 대상을 문서 템플릿의 대상 카드로 옮겼다 (대상 행으로, 또는 다른 대상의 속성으로)

## 02 · 과업별 화면 흐름 순서표와 화면 목록 (3.2절)

위에서 아래로 영역 다섯 개를 둡니다. 기본 흐름과 갈림길은 나중에 그대로 복사해 `context/screen-flow.md`에 붙일 수 있도록 **글자로** 씁니다.

| 영역 | 쓰는 것 |
|---|---|
| 핵심 과업 | 과업·불편 목록에서 고른 과업 한 문장 |
| 기본 흐름 | 화면 이름을 화살표로 이은 한 줄. 그림·배치 없이 이름만 |
| 갈림길 | [조건]과 다른 경로 한 줄 (없으면 비움) |
| 화면 목록 | 화면 이름 · 이 화면의 목적 · 측정 지표 1개 (표처럼 가로 한 줄에 상자 세 개) |
| 상태 화면 목록 | 상태 · 어느 화면 · 근거 데이터 · 보여 줄 것 (가로 한 줄에 상자 네 개) |

완료 기준 체크리스트
- [ ] 핵심 과업 1개의 기본 흐름을 처음부터 끝까지 화면 이름으로 이었다
- [ ] 갈림길이 있으면 조건과 함께 적었다
- [ ] 화면마다 목적과 측정 지표 1개를 적었다
- [ ] 상태 화면 4종(빈·오류·로딩·이상치)을 적고, 빈 상태와 이상치에는 근거 데이터를 붙였다
- [ ] 내용을 작업 폴더 `context/screen-flow.md`로 옮겼다

## 03 · Google Stitch로 만든 테마별 화면 시안 비교표 (3.5절)

테마마다 가로 한 줄을 쓰고, 열 6개를 둡니다.

| 열 | 쓰는 것 |
|---|---|
| 테마 | DESIGN.md 후보 쇼핑 목록의 테마 이름 |
| 시안 화면 | 화면 이름 2~3개와 Stitch에서 내보낸 시안 이미지 |
| 과업 수행 쉬움 | ○ / △ / × + 이유 한 줄 |
| 정보 위계 | ○ / △ / × + 이유 한 줄 |
| 프로필 적합성 | ○ / △ / × + 이유 한 줄 |
| 한 줄 결론 | 어느 테마의 어느 부분이 좋았는지, 첫 프로토타입을 어떤 테마로 만들지 |

완료 기준 체크리스트
- [ ] 테마 2개 이상 × 핵심 화면 2개 이상의 시안을 붙였다
- [ ] 세 기준을 모두 ○/△/×와 이유로 평가했다
- [ ] 테마마다 한 줄 결론을 적었다

## 공유

제출할 때 Figma 공유 설정에서 강사만 볼 수 있게 초대하거나 링크 공유 범위를 제한하고, 공유 링크를 내 워크시트 저장소의 `worksheet.md` 맨 위 Figma 링크 칸에 적습니다(교재 부록 A-3).
